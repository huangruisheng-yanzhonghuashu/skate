# 去哪滑 · 签到页（Tab）设计规范 v2.0

> 本规范定义微信小程序「签到」Tab 页（`pages/checkins`）的信息架构、视觉与交互。
>
> 依据：`DESIGN_SPEC.md` v1.0（街头、自由、年轻、活力）+ 产品规则（签到入口只在场所详情、Tab 签到页是记录页、顶部不放全局签到 CTA）。
>
> **v2 说明**：v1 只在旧页面基础上加描边、合并行，仍是一个「中性数据报表页」，违背规范 2.6「视觉保持张力，不因大众化而变成中性模板」。v2 推倒重来：把首页「品牌态度区」的基因带进签到页，用**大字标 + Hero 数据 + 贴纸**建立街头感，而不是在卡片上做小修小补。

---

## 1. 设计前提

### 1.1 签到页的任务

Tab「签到」不是入口，是**记录与社区比较页**。用户进来只有三件事：

1. **看势头**：最近滑得勤不勤 → 连续天数。
2. **看时间**：这个月哪些天去滑了 → 日历扫读。
3. **看别人**：本月谁滑得最多 → 社区排名与历史记录。

信息架构必须服务这个顺序：**态度头 → 连续 Hero → 日历 → 榜单 → 记录**。所有模块只展示真实数据，不做营销激励。

### 1.2 继承的视觉语言

- 页面底 `--bg` `#111114`，卡片 `--card` `#1E1E23`，全部加 1rpx 描边 `--line` `#26262C`。
- 品牌橙 `#FF5A36`：大字强调、连续天数、排名第一、贴纸描边。
- 语义绿 `#00D4AA`：**仅限**「我的行（已签到记录）」语义，不做装饰。
- 字体：系统字体栈；**大字标与 Hero 数字统一 italic（斜体）**，与首页 `brand-wordmark` 同构。
- 允许使用倾斜贴纸（rotate(-6deg)，规范 6.3），但每页不超过 1 处。
- 微动效 ≤250ms；按压态统一 `opacity: 0.7`（`.hv`）。

### 1.3 导航行规则

- 改为**自定义导航**（`navigationStyle: custom`），与首页同源。
- 导航行左侧留空（签到页无城市切换），**右侧为系统胶囊保留区，禁止放任何元素**。
- 标题表达全部交给页面内容区的「态度头」，不依赖原生导航标题。

## 2. v1 问题回顾（为什么重构）

| 问题 | 等级 | 说明 |
|---|---|---|
| **中性模板感** | P0 | 态度头 = 「签到记录」34rpx + 一行 slogan，像系统设置页，没有首页那种「84rpx 斜体去哪滑」的街头冲击。 |
| **Hero 缺位** | P0 | 连续天数被埋在三列统计带里，与「累计」「本月」平权，页面没有视觉焦点。 |
| **模块均等** | P1 | 统计带/日历/榜单三张同高卡片连续堆叠，扫读时没有节奏变化。 |
| **入口冗余** | P1 | 统计带三列都不可点，纯展示却占了一整张卡。 |
| **绿色滥用** | P2 | 记录行「场地」类型徽章用 #00D4AA，违反「绿仅在场/已签到语义」纪律。 |
| **下拉露白** | P2 | `checkins.json` 未设 `backgroundColor`。 |

v2 的核心动作：**砍卡、立 Hero、统一大字标**。

## 3. 信息架构 v2

### 3.1 模块顺序

```
① 态度头（无卡片，与首页品牌区同构）
   ├─ 大字标「轨迹」（斜体 72rpx）
   ├─ slogan「把每天留在街头。」（橙色 36rpx）
   ├─ 贴纸「STREAK · 12 天」（倾斜 -6deg，条件显示）
   └─ 品牌橙短条（80×8rpx）
② 连续 Hero（无卡片）
   ├─ 巨号数字「12」（斜体 120rpx，橙色）
   ├─ 标注「连续滑了（天）」
   └─ 次数据行「累计 86 次 · 本月 7 次」
③ 签到日历（卡片）
   ├─ 标题 + 切月箭头
   ├─ 已签 = 橙实心圆白字；今日未签 = 橙描边；今日已签 = 橙实心 + 白点
   └─ 未来日期弱化 40%
④ 本月签到榜（卡片）
   ├─ 标题 + 月份 chip
   ├─ 前三名奖牌语义（橙实底 / 灰描边 / 金描边）
   ├─ 我的行：青绿左缘（已签到语义）
   └─ 展开 / 收起
⑤ 最近记录（分组头 + 行列表，无卡片底）
   ├─ 分组头「最近记录」+ 副标「近 30 天 · N 条」
   ├─ 行：日期 + 场所名 + 类型徽章（场地灰 / 店铺橙）+ 箭头
   └─ 长按删除（二次确认）
```

### 3.2 v1 → v2 变化一览

| 维度 | v1 | v2 |
|---|---|---|
| 页面头 | 「签到记录」34rpx 小标题 | 斜体大字标「轨迹」72rpx + slogan + 橙条 + 贴纸 |
| 统计带 | 一卡三列，纯展示 | **删除**，并入连续 Hero 的次数据行 |
| 视觉焦点 | 无（四卡平权） | 连续天数 Hero：120rpx 斜体橙数字 |
| 日历已签 | 白字 + 6rpx 小点 | 橙实心圆白字 |
| 记录类型徽章 | 场地绿 / 店铺橙 | 场地灰 / 店铺橙（修正绿色纪律） |
| 我的行 | 橙底橙边 | 青绿左缘（已签到语义） |
| 导航 | 原生导航 | 自定义导航（胶囊区避让） |

### 3.3 首屏验收标准

iPhone 标准屏（812pt）不滚动必须看到：**态度头 + 连续 Hero 完整 + 日历标题与第一周日期**。用户第一眼知道「我最近滑得怎么样」。

## 4. 态度头（新增，与首页同构）

容器：`padding: 0 32rpx; margin-bottom: 32rpx;`

| 元素 | 规范 |
|---|---|
| 大字标 | `轨迹` / **72rpx** / `700` / `italic` / `#FFFFFF` / `letter-spacing: -1rpx`，与首页 `brand-wordmark` 同构（首页 84rpx，子页降一档）。 |
| slogan | `把每天留在街头。` / `36rpx` / `500` / `#FF5A36` / `line-height: 1.3`。态度文案，非激励文案（不出现「再签 N 天」）。 |
| 贴纸 | 条件显示（streak ≥ 3 才显示，避免新用户看到 0 天贴纸）：`STREAK · {{streak}} 天` / `22rpx` / `700` / `#FF5A36` / 透明底 / `border: 2rpx solid #FF5A36` / 圆角 8rpx / `rotate(-6deg)`，位于 slogan 行右侧。 |
| 品牌短条 | `80rpx × 8rpx`，圆角 999rpx，`#FF5A36`，margin-top 24rpx。 |

> 大字标用「轨迹」而非「签到」：签到是动作，轨迹是滑手留下的东西，更有街头档案感；同时避免与 Tab 文案机械重复。

## 5. 连续 Hero（新增，替代统计带）

容器：`padding: 0 32rpx; margin-bottom: 40rpx;`，**无卡片底**。

### 5.1 结构

```
12                    ← 巨号数字
连续滑了（天）         ← 标注
累计 86 次 · 本月 7 次  ← 次数据行
```

### 5.2 元素规范

| 元素 | 规范 |
|---|---|
| 巨号数字 | `120rpx` / `700` / `italic` / `#FF5A36` / `line-height: 1` / `letter-spacing: -2rpx`。streak = 0 时数字变 `#3A3A42`（空势态，不强调失败）。 |
| 标注 | `28rpx` / `#A6A6AD`，位于数字右下（baseline 对齐）或正下方。 |
| 次数据行 | `26rpx` / `#6E6E76`，格式：`累计 {total} 次 · 本月 {month} 次`。v1 统计带的三列数据压缩为一行，信息无损、空间减半。 |

### 5.3 为什么这样做

- 连续天数是滑手最有感知的**单一真实数据**，给 120rpx 的排面符合「视觉有态度」。
- 三列统计带删除后，首屏为日历让出约 180rpx 高度。
- 全部是可验证的真实数据，符合「内容克制」。

## 6. 签到日历

容器：`background: #1E1E23; border: 1rpx solid #26262C; border-radius: 20rpx; padding: 32rpx; margin: 0 32rpx 32rpx;`

### 6.1 头部

- 标题 `2026年9月`：`32rpx` / `600` / `#FFFFFF`。
- 切月箭头：`56rpx` 圆形 `--inset` 底，图标 `#A6A6AD`；当前月右箭头 `opacity: 0.35`。

### 6.2 日期状态（v2 强化）

| 状态 | 视觉 |
|---|---|
| 默认 | `26rpx` / `#A6A6AD`，占位 56rpx。 |
| 未来 | `opacity: 0.4`。 |
| 已签（非今日） | **橙实心圆** 56rpx，白字，`600` + `italic`。 |
| 今日未签 | **橙描边空心圆**（2rpx `#FF5A36`），橙字。 |
| 今日已签 | **橙实心圆**，白字，右下角 8rpx 白点。 |

### 6.3 动效

- 切月：日期网格 `translateX(±16rpx) + opacity 0.6 → 1`，`200ms ease-out`。
- `prefers-reduced-motion` 时关闭。

## 7. 本月签到榜

容器：同日历卡片。

### 7.1 头部

- 标题 `本月签到榜`：`32rpx` / `600` / `#FFFFFF`。
- chip：`20rpx` / `#FF8A6E` / `rgba(255,90,54,0.16)` / 胶囊。

### 7.2 行规范

- 行高 `96rpx`，分隔线 `1rpx #26262C`。
- 名次徽章：1 = `#FF5A36` 实底白字 italic；2 = `#A6A6AD` 描边；3 = `#FFB800` 描边；其余 `#6E6E76` 描边。
- 首字母头像 48rpx，四组暗渐变轮换（与首页 feed 同源）。
- 用户名 `28rpx / #FFFFFF`，次数 `28rpx / 600 / #FFFFFF` + `22rpx / #6E6E76`。

### 7.3 我的行

```css
background: rgba(0, 212, 170, 0.08);
border-left: 6rpx solid #00D4AA;
border-radius: 12rpx;
```

- 青绿 = 已签到语义，合规使用。
- 未上榜只显示 `我 · N 次`，不显示名次。

### 7.4 空态

- 文案 `26rpx / #6E6E76`：`本月还没有人签到，快去抢第一`（保留）。
- 下方幽灵按钮：`去看看附近场地`（2rpx 橙描边 + 橙字），点击 `wx.switchTab` 回首页。**不出现「立即签到」CTA**。

## 8. 最近记录

**无卡片底**（与首页「最新打卡」一样，用分组头立层级）。

### 8.1 分组头

```
最近记录              近 30 天 · 12 条
```

- 标题 `32rpx / 700 / #FFFFFF`，副标 `22rpx / #8C8C94`。

### 8.2 行规范

- 行高 `104rpx`，分隔线 `1rpx #26262C`，hover `opacity: 0.7`。
- 日期 `26rpx / #8C8C94`，宽 88rpx。
- 场所名 `28rpx / #FFFFFF`，flex 截断。
- 类型徽章（v2 修正绿色纪律）：
  - 场地：`#A6A6AD` 字 / `#26262C` 底。
  - 店铺：`#FF8A6E` 字 / `rgba(255,90,54,0.16)` 底。
- 箭头 `32rpx / #A6A6AD / opacity 0.6`。
- 点击进对应详情页；长按删除（`showModal` 二次确认，confirmColor `#E5484D`）。

### 8.3 空态

```
还没有签到记录
[去看看附近场地]（幽灵按钮 → 首页）
```

**禁止**出现「立即签到」「去签到」文案。

## 9. 空势态（streak = 0 与新用户）

- 态度头正常显示；贴纸在 streak < 3 时不显示。
- Hero 巨号数字 `0` 用 `#3A3A42` 弱化，标注与次数据行正常。
- 日历无已签点；榜单与记录走各自空态。
- 页面不隐藏任何模块，避免布局跳动。

## 10. 页面配置与交互

### 10.1 `checkins.json`

```json
{
  "navigationStyle": "custom",
  "enablePullDownRefresh": true,
  "backgroundColor": "#111114",
  "backgroundTextStyle": "light"
}
```

- `backgroundColor` 必填，防 iOS 下拉露白。
- 自定义导航需自行处理状态栏高度（复用首页 `statusBarHeight` / `navContentHeight` 计算方式）。

### 10.2 交互汇总

| 元素 | 行为 |
|---|---|
| 日历箭头 | 切月，不允许未来月 |
| 榜单行 | 点击进滑手主页 |
| 榜单展开 | 5 → 20 条，原地展开 |
| 记录行 | 点击进场地/店铺详情 |
| 记录长按 | 删除二次确认 → 刷新 |
| 空态按钮 | `wx.switchTab` 回首页 |

### 10.3 按压与动效

- 所有可点元素 `hover-class="hv"`（`opacity: 0.7` / 100ms）。
- 卡片入场 `fade-in 0.2s ease-out`。
- 全部动效 ≤250ms，尊重 `prefers-reduced-motion`。

## 11. 设计原则自检表

| 原则 | 落实点 |
|---|---|
| 信息层级清晰 | 态度头 → Hero → 日历 → 榜单 → 记录；首屏可见态度头 + Hero + 日历第一周。 |
| 视觉有态度 | 斜体大字标 + 120rpx 橙色 Hero 数字 + 倾斜贴纸，与首页 brand-wordmark 同构，不再是中性报表。 |
| 操作便捷 | 记录/榜单 1 步进详情；删除长按二次确认；切月原地完成。 |
| 轻量化 | 删掉统计带整卡；动效 ≤250ms；无默认弹层。 |
| 内容克制 | Hero 只展示真实 streak；无徽章/积分/激励文案；空态引导回首页而非假签到入口。 |
| 包容但不平庸 | 新手 3 秒看懂「这页记录我的滑行」；大字高对比适合户外；老手直接看榜单与日历密度。 |
