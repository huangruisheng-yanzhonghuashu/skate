# 去哪滑 · 发现页设计规范 v1.0

> 本规范面向 去哪滑 微信小程序「发现」页，基于首页已建立的街头视觉系统延伸。核心目标：把「发现」从工具化信息流改造成有社区感、有街头态度的滑板动态墙。

---

## 1. 设计前提

### 1.1 继承关系

发现页不是独立页面，而是首页同一套视觉语言的延续：

- 背景：`#111114`
- 卡片：`#1E1E23`，圆角 `24rpx`，边框 `1rpx solid #26262C`
- 品牌色：`#FF5A36`（橙），辅助 `#FF8A6E`
- 状态绿：`#00D4AA` 仅用于「在场/在线/已签到/营业中」
- 字体：系统默认字体，中文 PingFang SC / Roboto（Android），不引入额外字体文件

### 1.2 页面定位

发现页是**社区动态墙**：展示所有滑手的打卡内容（照片、视频、留言）。用户来这里是为了：

1. 看别人在哪滑、怎么滑
2. 发现新场地 / 店铺 / 俱乐部 / 培训
3. 给熟悉的内容点赞、评论
4. 在有今日签到记录的前提下，自己发打卡

### 1.3 打卡前提（业务硬规则）

- **发现页本身不能产生打卡**；打卡必须依附于一个已存在的场所实体。
- 可打卡的场所类型：**场地、板店、俱乐部、培训机构**。
- 用户当日必须已经在某个可打卡场所完成签到，才能在该场所下发打卡。
- 因此发现页 FAB 有两种状态：
  - **有今日签到记录**：显示橙色「发打卡」相机 FAB，点击进入 `post-publish` 并默认带入最近签到的场所。
  - **无今日签到记录**：显示次级灰色/描边「去签到」FAB，点击回到首页，引导用户先进入场所详情签到。
- 空态 CTA 同样遵循此规则：无签到时不显示「发第一条打卡」，改为「先找个场地签到」。

## 2. 当前问题分析

### 2.1 头部过重

- 自绘了一个「发现」标题行，加上微信小程序原生标题栏，造成双重标题浪费空间。
- 「最新/热门」Tab 样式太弱，像表单切换，不像社区筛选。
- 「发打卡」按钮和 Tab 挤在工具条里，位置不自然。

### 2.2 Feed 卡片不够街头

- 卡片圆角只有 `16rpx`，比首页 `24rpx` 小，系列感断裂。
- 用户名和时间在同一行，时间颜色浅但视觉上把名字推向左侧，不平衡。
- 类型标签「场地/店铺」是沉闷的灰色块，没有信息量。
- 场地名橙色链接单独成行，但被截断风险高。

### 2.3 媒体展示小气

- 单张图只有 `320rpx` 正方形，在全面屏手机里只占一半宽度，没有沉浸感。
- 视频直接渲染 `<video>` 在列表里，性能差、耗电、自动抢占层级。
- 多张图统一用九宫格，但 1 张图和 2 张图应有更戏剧化的展示。

### 2.4 互动区不醒目

- 点赞、评论图标只有 `36rpx`，数字紧挨图标，触控区靠负 margin 扩大，容易误触。
- 没有分享入口（滑板内容天然适合分享）。
- 评论区内嵌展开会撑高卡片，打断滚动位置。

### 2.5 空态太功能

- 「还没有打卡内容 / 去发一条打卡」像系统提示，没有街头态度。

## 3. 设计原则（针对发现页）

### 3.1 头部让位给内容

- 去掉自绘「发现」标题，使用原生导航栏标题（`navigationBarTitleText: '发现'`）。
- 最新/热门 Tab 上提到导航栏下方第一行，用大号分段选择器。
- 发打卡做成右下角悬浮按钮（FAB），不在头部抢位置。

### 3.2 Feed 卡片 = 街头海报

- 卡片圆角统一 `24rpx`，和首页一致。
- 头部信息更紧凑：头像 + 用户名 + 时间，场地名以「标签胶囊」形式紧跟其后。
- 媒体区域是卡片主角：单张图全宽 4:3，多张图按数量适配。
- 视频用封面图 + 播放按钮，不直接渲染 video。

### 3.3 互动直接可点

- 点赞、评论、分享三个动作横向排列，图标+数字，触控区明确。
- 评论不再内嵌展开，点击评论进入帖子详情页（复用 `post-detail`）。
- 点赞有心脏爆开动画（已存在，保留）。

### 3.4 空态有态度

- 文案不讨好，带点街头邀请感。
- 视觉用场地轮廓插画 + 橙色 CTA。

### 3.5 微动效 ≤250ms

- 卡片错峰入场 0.25s。
- Tab 切换指示条 0.2s。
- 点赞心脏爆开 0.35s（情感峰值，可略超但仍短促）。

## 4. 信息架构

```
发现页
├── 原生导航栏：「发现」
├── 顶部工具条（sticky）
│   ├── 最新 / 热门 分段选择器
│   └── 右侧：筛选/搜索入口（可选）
├── Feed 列表
│   └── 动态卡片
│       ├── 头部：头像 + 用户名 + 时间
│       ├── 场地胶囊（可点击）
│       ├── 文字内容（最多 3 行，展开进详情）
│       ├── 媒体区
│       │   ├── 1 张：全宽 4:3
│       │   ├── 2 张：左右各 50%
│       │   ├── 3 张：一大两小（左大右上下）
│       │   └── 4+ 张：九宫格

├── 加载更多 / 没有更多了
└── 空态 / 失败态
└── 发打卡 FAB（右下角固定）
```

## 5. 组件规范

### 5.1 顶部分段选择器

```
背景：透明
未选中：font-size 28rpx，color #8C8C94，font-weight 500
选中：font-size 32rpx，color #FF5A36，font-weight 700
指示条：宽 32rpx，高 6rpx，圆角 999rpx，渐变 #FF5A36 → #FF8A6E
间距：两个选项之间 48rpx
```

### 5.2 动态卡片

```
容器：bg #1E1E23，border 1rpx solid #26262C，border-radius 24rpx，padding 24rpx
头像：72rpx 圆形，无渐变，用用户头像或首字占位
用户名：30rpx，#FFFFFF，font-weight 600
时间：24rpx，#6B6B75，右对齐
场地胶囊：bg rgba(255,90,54,0.14)，color #FF8A6E，font-size 22rpx，padding 8rpx 16rpx，圆角 999rpx
文字内容：28rpx，#D9D9DE，line-height 1.6，最多 3 行，超出省略
```

### 5.3 媒体区

| 数量 | 布局 | 尺寸 |
|---|---|---|
| 1 张 | 全宽 4:3 | width 100%，aspect-ratio 4/3，圆角 16rpx |
| 2 张 | 左右并排 | 各 50%，间距 12rpx，aspect-ratio 1/1 |
| 3 张 | 左大右上下 | 左 60% 4:3，右 40% 上下各 1:1 |
| 4+ 张 | 九宫格 | 三列，间距 8rpx，aspect-ratio 1/1 |

视频统一显示封面图（取第一帧或 photos 首图），中心叠加播放按钮：

```
播放按钮：56rpx 圆形，bg rgba(17,17,20,0.55)，backdrop-filter blur
三角形：18rpx 宽，白色，drop-shadow
上传中角标：左下，bg rgba(0,0,0,0.55)，font-size 22rpx
```

### 5.4 互动区

```
容器：flex row，gap 48rpx，margin-top 20rpx
动作项：flex row，gap 10rpx，min-height 72rpx，padding 16rpx 0（扩大触控）
图标：36rpx
数字：26rpx，color #8C8C94；点赞后 color #FF5A36
```

### 5.5 发打卡 FAB（受签到状态控制）

**有今日签到时（可打卡）：**

```
位置：fixed，right 32rpx，bottom calc(140rpx + env(safe-area-inset-bottom))
尺寸：112rpx × 112rpx
背景：渐变 #FF5A36 → #FF8A6E
图标：相机，白色，40rpx
阴影：0 8rpx 32rpx rgba(255,90,54,0.35)
```

**无今日签到时（引导签到）：**

```
位置同上
尺寸：112rpx × 112rpx
背景：#1E1E23
边框：2rpx solid #FF5A36
图标：location-dot，#FF5A36，40rpx
文字（图标下方小字）：「去签到」
阴影：0 8rpx 32rpx rgba(0,0,0,0.3)
```

### 5.6 空态

**有今日签到时：**

```
插画：滑板场轮廓线稿，stroke #FF5A36，opacity 0.3
主文案：32rpx，#FFFFFF，font-weight 600
副文案：26rpx，#8C8C94
CTA：橙色渐变胶囊，文字「发第一条打卡」
```

**无今日签到时：**

```
主文案：这片场地还没人滑
副文案：先找个场地签到，再留下你的痕迹
CTA：橙色渐变胶囊，文字「去附近场地签到」
```

### 5.7 点赞态与评论态

**点赞态（feed 卡片与详情页通用）：**

```
未点赞：far fa-heart，36rpx，#8C8C94，数字 #8C8C94
已点赞：fas fa-heart，36rpx，#FF5A36，数字 #FF5A36，font-weight medium
动画：点击时 0.15s scale 1.25 回弹（心脏爆开可另加粒子，不强求）
```

**评论态：**

- 发现页 feed 卡片**不内嵌展开评论**，点击评论区域进入帖子详情。
- 帖子详情页互动统计行保留：点赞数、评论数、分享。下方评论列表头部使用「全部评论」，不再重复数量。
- 帖子详情页底部固定输入栏：

```
容器：fixed，left 0，right 0，bottom 0，height calc(112rpx + env(safe-area-inset-bottom))，bg #1E1E23，border-top 1rpx #26262C
输入框：flex-1，height 72rpx，bg #111114，border-radius 999rpx，padding 0 28rpx，font-size 28rpx，color #FFFFFF，placeholder #6E6E76
发送按钮：96rpx 宽，height 64rpx，bg 渐变 #FF5A36 → #FF8A6E，color #FFFFFF，font-size 26rpx，font-weight 600，border-radius 999rpx
输入为空时发送按钮 disabled：bg #26262C，color #6E6E76
```

- 评论列表：

```
头像：56rpx 圆形
用户名：26rpx，#FFFFFF，font-weight 600
时间：22rpx，#6E6E76
内容：28rpx，#D9D9DE，line-height 1.6
回复对象：@用户名 用 #FF8A6E
```

### 5.8 操作反馈（Toast / Snackbar）

所有关键操作需要给用户明确反馈，但反馈必须克制，不中断当前浏览：

**点赞成功：**

```
形式：底部轻量 Snackbar
容器：fixed，left 50%，bottom 160rpx，transform translateX(-50%)
背景：#1E1E23，border 1rpx #26262C，border-radius 999rpx
内边距：16rpx 32rpx
内容：图标（橙色实心小心）+ 文字「已点赞」
文字：26rpx，#FFFFFF
动效：0.2s fade-in + 0.15s slide-up；停留 1.5s 后 0.2s fade-out
```

**取消点赞：**

```
内容：图标（灰色空心小心）+ 文字「已取消点赞」
文字：26rpx，#8C8C94
```

**评论成功：**

```
形式：底部轻量 Snackbar
内容：文字「评论已发布」
同时：新评论以 0.25s 动画插入列表顶部
```

**评论失败 / 点赞失败：**

```
形式：底部 Snackbar
内容：「网络不太稳，再试一次」
颜色：#FF3B30（error）图标 + #FFFFFF 文字
```

**发送按钮 loading：**

```
发送中按钮显示 loading 圆点（白色，直径 8rpx，3 个），按钮本身 disabled
```

### 5.9 搜索功能

发现页搜索用于从社区流中快速定位**滑手、场地、打卡内容**。不做全局场地搜索（那是首页的职责），也不做用户搜索的独立页面。

#### 触发入口

```
位置：顶部 Tab 工具条最右侧
图标：searchAsh，24rpx
容器：w-72rpx，h-72rpx，rounded-full，bg #17171B
```

#### 搜索展开态

点击搜索图标后，顶部工具条切换为搜索输入栏：

```
容器：fixed / sticky，top 0，z-index 20，bg #111114，border-bottom 1rpx #26262C，px 32rpx，py 24rpx
输入框包裹：flex-1，h 80rpx，bg #1E1E23，border 1rpx #26262C，rounded-full，px 28rpx
图标：搜索 icon 在左侧，20rpx，#8C8C94
输入框：font-size 28rpx，color #FFFFFF，placeholder #6E6E76
清空按钮：query 非空时右侧显示 ×，28rpx，#8C8C94
取消按钮：右侧「取消」文字，28rpx，#8C8C94
```

输入时原 Tab / feed 被搜索态覆盖；点「取消」或返回按钮回到 Tab 浏览态。

#### 搜索范围

1. **滑手昵称**（`userName`）
2. **场地/店铺/俱乐部/培训机构名称**（`venueName`）
3. **打卡文字内容**（`note`）

搜索按「或」关系匹配；不区分大小写。

#### 搜索策略

```
输入为空：显示「最近搜索」历史 chips（最近 8 条，可一键清除）
输入 ≥1 字符：300ms 防抖后触发云端搜索
搜索中：列表顶部显示骨架屏（3 行 feed 占位）
有结果：使用 feed 卡片模板渲染，按时间倒序
无结果：空态插画 + 文案「没找到相关内容，换个关键词试试」
```

云端实现（MVP）：使用 `db.RegExp` 在 `checkins` 表中对 `userName`、`venueName`、`note` 做正则匹配，并叠加「有内容」过滤（note/photos/videos 非空）。结果集 ≤ 50 条，前端按时间倒序展示，不再分页。

**搜索历史存储：** 使用 `wx.setStorageSync('discover_search_history', [...])`，上限 8 条，去重，新搜索置顶。

#### 搜索空态

```
插画：放大镜 + 滑板场轮廓，stroke #FF5A36，opacity 0.25
主文案：28rpx，#FFFFFF，font-weight 600
副文案：26rpx，#8C8C94
```

## 6. 交互规则

1. **进入页面**：默认「最新」Tab，加载 20 条；同步检查今日签到记录，决定 FAB 状态。
2. **切换 Tab**：最新按时间倒序；热门按「点赞×2 + 评论×3」排序。切换时列表重新排序，不重新请求。
3. **点击头像/用户名**：进入滑手主页 `user-profile`。
4. **点击场地胶囊**：进入场地/店铺/俱乐部/培训详情。
5. **点击媒体**：进入全屏内容预览 `media-viewer`，隐藏底部 TabBar。
   - 视频：单条全屏预览，封面 + 播放按钮，不自动播放；右下角浮出「点赞 / 评论 / 转发」操作按钮组。退出走系统返回 / 左侧滑回，与首页场地详情返回方式一致，预览层内部不放关闭按钮。
   - 图片：1–9 张可左右滑动预览，顶部计数器 + 底部分页圆点；点击图片任意区域关闭。
   - 顶部不放置任何自定义按钮，避免与微信小程序系统胶囊按钮 / 返回区冲突。
6. **点击评论数/评论图标**：进入帖子详情 `post-detail`（不再内嵌展开评论区）。
7. **点击点赞**：本地即时反馈（图标变橙色实心、数字 +1）+ 0.15s 心脏缩放动画；请求成功后显示「已点赞」Snackbar，失败时回滚并提示「网络不太稳，再试一次」。
8. **点击评论发送**：按钮进入 loading，成功后输入框清空、新评论插入列表顶部并显示「评论已发布」，失败时提示重试。
9. **点击 FAB（有签到）**：进入 `post-publish`，默认带入最近签到场所。
10. **点击 FAB（无签到）**：回到首页，toast 提示「先找个场地签到，才能发打卡」。
10. **下拉刷新**：重新加载 feed 和签到状态。
11. **上拉加载**：每次 20 条。

## 7. 禁止项

- 不在头部放自绘标题栏。
- 不在 feed 卡片里直接渲染 `<video>`。
- 不内嵌展开评论区（改进入详情页）。
- 不使用紫色/靛蓝等禁用色。
- 不使用 emoji 作为图标。

## 8. 帖子详情页（评论场景）

发现页点击评论后进入帖子详情，结构如下：

```
帖子详情页
├── 原生导航栏：「帖子」+ 返回
├── 帖子内容（复用 feed 卡片头部 + 媒体 + 文字）
├── 互动统计行：点赞数 · 评论数 · 分享
├── 评论列表
│   └── 评论项：头像 + 用户名 + 时间 + 内容（+ 回复对象）
├── 加载更多 / 没有更多了
└── 底部固定评论输入栏
```

**禁止项：**
- 不在帖子详情内再嵌套一个帖子列表。
- 评论输入栏不遮挡最后一条评论（列表底部 padding 112rpx）。

## 9. 可访问性

- 所有按钮加 `aria-role` 和 `aria-label`。
- 图片加 `alt` 或 `aria-label`。
- 颜色对比度满足 WCAG 4.5:1。
