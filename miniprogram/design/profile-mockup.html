v2 设计说明

  • 01 态度头与签到页同语系：「档案 / 这是你的轨迹。」与「轨迹 / 把每天留在街头。」呼应。
  • 02 滑手 ID 卡：顶部 8rpx 橙渐变卡缘 + 144rpx 橙环头像 + 48rpx 斜体昵称，身份感来源；空身份牌也保留橙条。
  • 03 擅长标签从橙底胶囊改为描边贴纸（2rpx 橙边、首个微倾斜），与全站贴纸语言一致。
  • 04 数据带去卡化：数字本身就是内容，48rpx 斜体、签到橙色聚焦，包装减半。
  • 05 菜单图标统一 72rpx 橙色方块，与首页胶囊/贴纸语言连通，按压统一 opacity 0.7。
  • 06 编辑资料底部 sheet：85vh、把手、保存放右上角，避免键盘遮挡，与全站弹层形态统一。
