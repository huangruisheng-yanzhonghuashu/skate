去哪滑 - 首页 UI 设计稿

基于《去哪滑设计规范 v1.0》输出，暗色街头风格，社区前置，地图收起。

DESIGN SPECIFICATION

1. Purpose Statement

为滑板爱好者提供附近场地、俱乐部、板店信息，并营造「有人正在滑」的社区氛围。首页需要在 3 秒内让用户感受到街头能量。

2. Aesthetic Direction

Brutalist/raw street — 深色水泥灰底、荧光色点缀、粗粝排版、街头贴纸感。

3. Color Palette

4. Typography

系统字体栈：PingFang SC / Helvetica Neue / Arial。标题加粗、正文常规，户外可读优先。

5. Layout Strategy

纵向信息流：导航行 → 品牌态度区 → 在线热度 → 最新打卡 → 地图入口 → 搜索+Tab → 列表。社区内容前置，地图默认收起，避免标准工具 App 的搜索框居中布局。

* 本项目为微信小程序，使用系统字体栈作为品牌字体，覆盖 ui-design 默认字体限制。
