# 去哪滑 设计规范 v1.0

> 本规范面向 去哪滑 微信小程序（原生小程序），用于统一首页及核心页面的视觉、交互与信息架构。所有设计决策以「街头、自由、年轻、活力」为核心，在滑板大众化的背景下保持态度、提升包容。

---

## 1. 设计哲学

### 1.1 核心关键词

街头、自由、年轻、活力。

### 1.2 态度声明

滑板文化的本质是街头、自由、不服输。去哪滑 的 UI 要传达的不是「精致优雅」，而是：

> **粗粝中有态度，简洁中有能量。**

大众化的趋势不应该把产品稀释成「又一个场地工具」。恰恰相反，当市场上都是标准化的本地生活产品时，有态度、有社区感、有滑板基因的设计才更稀缺。

### 1.3 大众化的设计回应

核心关键词不变，但表达方式升级：

| 原表达 | 升级表达 |
|---|---|
| 硬核街头 | 开放街头 |
| 粗粝 | 粗粝且精致 |
| 圈内感 | 包容但有味 |
| 功能列表 | 社区前置 |
| 暗色 + 橙 | 有能量感的街头视觉 |

新增原则：**包容但不平庸**——新手看得懂，老手觉得有味道。

## 2. 设计原则

### 2.1 信息层级清晰

滑手往往在户外快速扫一眼手机，字号、对比度必须够大够清晰。

- 首屏核心信息不超过 3 层。
- 关键行动按钮（导航、签到）在 1-2 步内可达。
- 同一页面内，功能入口不重复出现超过一次。

### 2.2 视觉有态度

深色/水泥灰背景 + 高饱和荧光色点缀，营造街头感。

- 背景用深炭黑，卡片用水泥灰，制造街头地面的质感。
- 品牌色 #FF5A36（荧光橙）用于主按钮、选中态、重点标签。
- #00D4AA（荧光绿）仅用于「在场 / 在线 / 已签到 / 营业中」等正向状态，不可泛化。

### 2.3 操作便捷

所有核心操作（签到、导航、筛选）在 1-2 步内完成。

- 签到入口只在场所详情底部操作栏，定位硬校验。
- Tab「签到」页是记录页（累计 / 日历 / 榜单 / 记录），不是入口。
- 任何页面顶部不放全局「去签到」CTA——微信小程序右上角是胶囊按钮区，导航行右侧不可放操作。

### 2.4 轻量化

小程序基因是「用完即走」，不堆砌花哨动效。

- 微动效时长 ≤ 250ms。
- 首屏不默认展开大地图。
- 不加载与当前目标无关的模块。

### 2.5 内容克制

不加多余内容：

- 无营销式激励文案（如「再打 1 天解锁 xx 徽章」）。
- 无凑数模块（如重复的分类入口）。
- 庆祝/结果态只反馈真实数据（签到成功 + 连续天数即止）。

### 2.6 包容但不平庸

- 文案和图标避免只有圈内人才懂的梗。
- 视觉保持张力，不因大众化而变成中性模板。
- 新用户 3 秒内能明白这个小程序是做什么的。

## 3. 色彩系统

### 3.1 背景色

| Token | 色值 | 用途 |
|---|---|---|
| `--bg` | `#111114` | 页面底色 |
| `--card` | `#1E1E23` | 卡片、面板背景 |
| `--inset` | `#17171B` | 输入框、 recessed 区域 |
| `--sheet` | `#232329` | 浮层、弹窗面板 |
| `--line` | `#26262C` | 分割线、边框 |
| `--sheet-line` | `#2F2F36` | 浮层内部分割线 |

### 3.2 品牌色

| Token | 色值 | 用途 |
|---|---|---|
| `--primary` | `#FF5A36` | 主按钮、选中态、重点标签、品牌强调 |
| `--primary-lt` | `#FF8A6E` | 辅助文字、hover/pressed 态 |
| `--primary-50` | `rgba(255, 90, 54, 0.16)` | 浅色背景、tag 填充 |
| `--primary-100` | `rgba(255, 90, 54, 0.24)` | 高亮背景 |
| `--primary-600` | `#FF8A6E` | 渐变终点 |

### 3.3 语义色

| Token | 色值 | 用途 |
|---|---|---|
| `--success` | `#00D4AA` | 在场、已签到、在线、营业中 |
| `--warning` | `#FFB800` | 提醒、待处理 |
| `--error` | `#FF3B30` | 错误、下架、删除 |
| `--info` | `#2A8CFF` | 信息提示、链接 |

**重要纪律**：绿色（#00D4AA）只能用于「在场/在线/已签到/营业中」语义，不可用于普通标签或装饰。

### 3.4 文字色

| Token | 色值 | 用途 |
|---|---|---|
| `--t1` | `#FFFFFF` | 主标题、重要文字 |
| `--t2` | `#D9D9DE` | 正文 |
| `--t3` | `#A6A6AD` | 次要说明 |
| `--t4` | `#8C8C94` | 占位、禁用 |
| `--t5` | `#6E6E76` | 最弱提示 |

### 3.5 使用规则

- 深色背景上，主文字用 `--t1`（#FFFFFF），次要文字用 `--t3`。
- 品牌色只用于需要用户注意的元素，避免大面积铺色。
- 状态色不可用于装饰，必须对应真实语义。

## 4. 字体系统

### 4.1 字体族

```css
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Helvetica Neue', Arial, sans-serif;
```

### 4.2 字号层级

| 层级 | 字号 | 用途 | 最小字重 |
|---|---|---|---|
| Display | 40-48rpx | 首屏品牌 slogan、大标题 | 500 |
| H1 | 36rpx | 页面标题、模块大标题 | 500 |
| H2 | 30-32rpx | 卡片标题、场所名 | 500 |
| H3 | 26-28rpx | 小标题、城市名、按钮文字 | 500 |
| Body | 24-26rpx | 正文、地址、描述 | 400 |
| Caption | 20-22rpx | 时间、辅助说明、标签 | 400 |

### 4.3 户外可读性

- 重要信息字号不小于 24rpx。
- 主标题与背景对比度至少 7:1。
- 避免使用细体（font-weight < 400）。
- 行高 1.35-1.5，标题行高 1.2。

## 6. 图标与图形

### 6.1 图标风格

- 线性图标，2rpx 描边。
- 端点圆角。
- 无渐变、无阴影。
- 风格偏向街头/运动，拒绝 Emoji 或商务图标。

### 6.2 图标尺寸

| 场景 | 尺寸 |
|---|---|
| TabBar 图标 | 42rpx |
| 列表内图标 | 24-28rpx |
| 按钮内图标 | 28-32rpx |
| 空态图标 | 80-120rpx |

### 6.3 图形元素

- 可适当使用倾斜标签（如「热门」贴纸 rotate(-6deg)）。
- 标签、按钮可带 2rpx 细边框，制造街头贴纸感。
- 避免大面积几何装饰，保持简洁。

## 7. 动效规范

### 7.1 时长

| 类型 | 时长 |
|---|---|
| 微反馈（hover/pressed） | 100-150ms |
| 内容切换（Tab、筛选） | 200-250ms |
| 卡片入场 | 200-300ms |
| 地图展开/收起 | 250ms |

**所有动画不得超过 300ms。**

### 7.2 缓动

- 默认：`ease-out` 或 `cubic-bezier(0.25, 0.46, 0.45, 0.94)`。
- 弹性反馈（如指示条缩放）：`cubic-bezier(0.34, 1.56, 0.64, 1)`。
- 避免线性动画。

### 7.3 原则

- 动效是信息，不是装饰。
- 优先使用 opacity 和 transform，避免触发布局重排。
- 尊重系统「减弱动效」设置：`@media (prefers-reduced-motion: reduce)` 关闭非必要动画。

## 8. 首页信息架构

### 8.1 模块顺序（从上到下）

1. **状态栏 / 导航行**
   - 左侧：城市入口（定位图标 + 城市名 + 切换图标）。
   - 右侧：为微信胶囊按钮保留空间，不放任何操作。

2. **品牌态度区**
   - 大字品牌名「去哪滑」（44px 斜体，白色）。
   - 固定主口号「想去哪滑，就去哪滑。」22px，**错位双行**（不再做每日动态文案，内容克制）：
     - 第一行「想去哪滑，」灰色（--t2），左对齐；
     - 第二行「就去哪滑。」白色（--t1），右缩进一字（22px）形成错位；文字下缘压**全页唯一一处**橙色马克笔高亮——高约四成字高（22px 字号配 9px），贴住文字下缘（bottom 1px），`rgba(255,90,54,0.8)` 鲜橙（禁止低透明度棕褐化），-2° 斜切 + 2px 圆角，右端出血 6px、左端 2px，笔触为背景层；
     - 两行行距收紧至 1.25，口号块与大标题构成一块海报；
     - 「在线热度」胶囊与双行口号同一行，垂直居中（`items-center`），`flex-shrink:0` 不被挤压。
   - 口号入场动效：两行 80ms 错峰淡入 + 上移 8px（各 200ms），仅首次进入播放。
   - 下方橙色短划线装饰保留。

3. **在线热度**
   - 荧光绿脉冲点 + 数字 +「人在滑」。
   - 胶囊容器，边框可用品牌色强调。

4. **最新打卡**
   - 标题「最新打卡」+ 副文案「实时社区」。
   - 横滑卡片：封面/视频首帧 + 用户名 + 场地 + 时间。
   - 无数据时整区隐藏。

5. **地图入口（默认收起）**
   - 横向卡片：小地图预览 + 「附近场地地图 · 城市 · N 个场地」。
   - 点击后展开到半屏或全屏地图。

6. **搜索 + 一级 Tab**
   - 搜索框为胶囊形态，placeholder 用街头语气（如「搜场地 / 俱乐部 / 板店」）。
   - 一级 Tab：场地 / 板店 / 俱乐部 / 培训机构。
   - 选中态：白色粗体 + 橙色短指示条。

7. **二级筛选**
   - 场地 Tab：类型 chips（全部 / 碗池 / 街式 / 平地 / U池 / 混合）。
   - 机构 Tab：服务 chips（卖板 / 教学 / 维修 / 配件 / 服装 / 组织活动 / 装备租赁 / 场地运营）。
   - 激活态：浅橙背景 + 橙边框 + 橙字。

8. **场地/机构列表**
   - 行化卡片，左图右文。
   - 名称、地址、标签、状态行。
   - 状态行优先显示「此刻 N 人在场」或「今日已签到」。

9. **底部引导**
   - 轻量一行：「还有漏掉的场地？推荐给我们」。

10. **底部 TabBar**
    - 首页 / 发现 / 签到 / 我的。
    - 激活态：橙色渐变胶囊包住图标+文字。

### 8.2 禁止项

- 首屏顶部不放全局「去签到」按钮。
- 同一分类入口不在同一页面重复出现。
- 地图不默认展开超过半屏。
- 首页不放置营销弹窗、激励文案、广告横幅。

## 9. 组件规范

### 9.1 按钮

**主按钮**
- 背景：`--primary` (#FF5A36)。
- 文字：白色，字号 28rpx，字重 500。
- 圆角：`--radius-pill` 或 `--radius-md`。
- 高度：80-88rpx。
- 按压态：透明度 0.9 或背景变深。

**次要按钮（幽灵按钮）**
- 背景：透明。
- 边框：2rpx solid `--primary`。
- 文字：`--primary`。
- 用于取消、重置、次要行动。

### 9.2 标签

**类型标签**
- 背景：`--primary-50`。
- 文字：`--primary-lt`，字号 22rpx。
- 圆角：`--radius-sm`。
- 用于场地类型、服务类型。

**状态标签**
- 在场/已签到：绿色文字 + 绿色脉冲点。
- 热门：橙色背景贴纸，可轻微倾斜 rotate(-6deg)。
- 暂无：灰色文字 + 灰色点。

### 9.3 卡片

**场地卡片**
- 背景：`--card`。
- 圆角：`--radius-lg`。
- 左图：200rpx × 200rpx，撑满卡高，左缘圆角。
- 标题：30rpx，白色，字重 500，单行截断。
- 地址：24rpx，`--t4`。
- 标签行：22rpx 类型标签。
- 状态行：24rpx，绿色/灰色。

**打卡卡片**
- 宽度：280rpx。
- 封面：16:10 或 4:3。
- 用户名 + 场地名 + 时间。
- 视频封面带播放角标。

### 9.4 Tab

**一级 Tab**
- 文字：30rpx，未选中 `--t3`，选中 `--t1` + 字重 500。
- 指示条：橙色短条，48rpx 宽，6rpx 高，选中时 scale 展开。
- 切换动画：200-250ms。

**底部 TabBar**
- 背景：`--bg`。
- 未选中：图标 + 文字 `--t4`。
- 选中：橙色渐变胶囊，白色图标 + 文字。
- 高度：120rpx + safe-area。

### 9.5 搜索

- 胶囊形态，背景 `--inset`。
- placeholder：`--t5`。
- 左侧搜索图标，右侧清空按钮。
- 展开后显示取消按钮。

### 9.6 地图入口

- 默认收起为横向卡片。
- 左侧小地图预览（76×56px 圆角）：**必须用「路网 + 街区」画法**——1~2 条主路（粗）+ 支路（细）+ 2~3 个浅色街区色块 + 中央橙色定位 pin（非圆点）+ 次场地小圆点；禁止用均匀网格纹理冒充地图（读起来像图表）。
- 右侧文案：标题 + 城市 · N 个场地。
- 点击后展开到地图页或半屏地图。展开态地图高度不超过 50vh；大地图底纹同一路网画法，可加水系色块，venue pin 复用主色。

### 9.7 空态

- 滑板线稿图标或场地图标。
- 标题：28rpx，`--t3`。
- 副文案：26rpx，`--t4`。
- 行动按钮：幽灵按钮，引导切换城市/查看全部/推荐场地。

## 10. 产品规则

### 10.1 签到入口

- **唯一入口**：场所详情页底部操作栏。
- 签到必须依托场所，定位硬校验。
- Tab「签到」页是记录页，不是入口。
- 任何页面顶部不放全局「去签到」CTA。

### 10.2 导航行

- 城市切换在导航行左侧。
- 导航行右侧为胶囊保留区，不放任何操作按钮。

### 10.3 城市切换

- 首页点击城市入口进入城市选择页。
- 城市选择页返回后，地图中心自动移到新城市第一个实体。
- 自动定位只在云端有该城市数据时切换，避免空首页。

### 10.4 内容克制

- 无营销式激励文案。
- 无凑数模块。
- 庆祝/结果态只反馈真实数据。

---

## 11. 可访问性

- 所有交互元素最小点击区域 88rpx × 88rpx。
- 图片/视频提供有意义的 aria-label。
- 颜色不是唯一信息载体（如在线状态同时用文字和绿点）。
- 支持系统减弱动效设置。
