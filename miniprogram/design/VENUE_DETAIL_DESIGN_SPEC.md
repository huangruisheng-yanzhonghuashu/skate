# 去哪滑 · 场地详情页设计规范 v1.0

> 本规范定义 去哪滑 微信小程序「场地详情页」（`pages/venue-detail`）的信息架构、视觉与交互。
> 依据：`DESIGN_SPEC.md` v1.0（街头、自由、年轻、活力）+ `VENUE_DETAIL_AUDIT.md` v1.0（审计结论 P0–P4）。
> 姊妹页：`shop-detail`（机构详情）同构复用本规范（星级 / 标签 / 操作栏 / 弹层规则一致，差异在第 10 节说明）。

---

## 1. 设计前提

### 1.1 详情页的任务

用户从首页列表点进详情页，只有三个目的：

1. **决策**：这地方值不值得去？→ 评分、距离、类型、现在有没有人
2. **行动**：导航过去 / 到了签到 / 签完发打卡
3. **看氛围**：最近大家在这滑得怎么样 → 打卡动态

信息架构必须服务这个顺序：决策信息全部进首屏，行动按钮固定在底部 1 步可达，氛围内容随后。

### 1.2 继承的视觉语言

- 页面底 `--bg` `#111114`，卡片 `--card` `#1E1E23`，浮层 `--sheet` `#232329`
- 品牌橙 `#FF5A36`：主按钮、首标签、评分数字、距离 pill、热门贴纸（「本周 N 人来滑」）
- 语义绿 `#00D4AA`：**仅限**「在场 / 已签到」语义，做点缀不做铺色
- 文字阶梯：`#FFFFFF` / `#D9D9DE` / `#A6A6AD` / `#8C8C94` / `#6E6E76`
- 微动效 ≤250ms；所有动画优先 opacity / transform

### 1.3 导航行规则

- 自定义导航（`navigationStyle: custom`），头图沉浸式铺满。
- **左侧**：返回按钮（白色 ←，88×88rpx 触控区，圆形毛玻璃底 `rgba(17,17,20,0.55)` + `backdrop-filter: blur(8rpx)`）。
- **右侧**：系统胶囊保留区，禁止放任何元素（报错、分享等均不得入此区）。

## 2. 信息架构

### 2.1 模块顺序（从上到下）

```
① 头图区（38vh，min 480rpx）
   ├─ 轮播图 / 无图占位
   ├─ 返回按钮（左上悬浮）
   ├─ 底部渐变 160rpx
   ├─ 场地名称 44rpx（叠图左下）
   ├─ 热门贴纸「本周 N 人来滑」（条件显示，名称行右侧，rotate(-6deg)）
   └─ 计数器 n/N（右下，多图时）
② 信息卡（--card，圆角 16rpx，margin 24rpx 32rpx 0）
   ├─ 评分行：五颗星 + 分数 + N人评价 ……… 距离 pill
   ├─ 地址行：pin + 地址（最多两行）
   ├─ 标签行：首标签橙色 + 其余灰（最多 3 个 + 溢出 +N）
   ├─ 运营方行（条件显示，左橙线 chip 卡）
   └─ 报错入口（地址行行尾小字，旗图标 + 「报错」）
③ 今日打卡卡（--card + 左侧 3rpx 橙线）
   ├─ 「今日 N 位滑手打卡」（纯排版，数字白字加重，无图标无脉冲）
   └─ 今日打卡滑手头像 ×4 + 折叠 +N（今日无人打卡时整块弱化）
④ 打卡动态
   ├─ 标题「打卡动态」+ 查看全部 ›
   └─ feed 卡（与发现页同款，最多 3 条）
⑤ 底部固定操作栏（固定三键，键位不随状态跳动）
   导航 128rpx │ 主键 flex（签到 / 发打卡） │ 副键 128rpx（发打卡 / 已签到）
⑥ 弹层（全部底部 sheet，形态统一）
   发打卡 sheet / 报错 sheet / 评分 sheet
⑦ 签到庆祝层（瘦身版：徽章 + 成功 + 连续天数，≤250ms，1.2s 自动消失）
```

### 2.2 首屏验收标准

在 iPhone 标准屏（812pt）上，不滚动必须看到：**名称、评分、距离、地址、至少 1 个标签、在场状态**。这是本规范的核心硬指标。

## 4. 信息卡

容器：`background: #1E1E23; border-radius: 16rpx; margin: 24rpx 32rpx 0; padding: 32rpx; position: relative;`

### 4.1 评分行（第一行，可点击 → 评分 sheet）

```
[★★★★★] [4.8] [· 236人评价]        [距你 1.2km]
```

| 元素 | 规范 |
|---|---|
| 五颗星 | 双层裁剪（灰底 + 橙前景按分数比例），单星 30rpx，间距 4rpx |
| 分数 | 30rpx / 600 / `#FF5A36` |
| 评价人数 | 22rpx / `#8C8C94`，「· N人评价」；N=0 时显示「· 暂无评价」 |
| 距离 pill | 右侧对齐，`rgba(255,90,54,0.16)` 底 + `#FF8A6E` 字，24rpx / 600，胶囊；定位失败时隐藏 |
| 整行触控 | hover-class 透明度 0.75，点击打开评分 sheet |

> 评分从图上移到此处：与距离组成「决策行」，户外一次扫完；同时解除与 swiper 的手势冲突。

### 4.2 地址行

- pin 图标 32rpx（橙色）+ 地址文字 28rpx / `#A6A6AD`，最多两行，行高 1.5。

### 4.3 标签行

- 最多展示 **3 个**，溢出折叠为「+N」灰胶囊。
- **首标签橙色高亮**：`rgba(255,90,54,0.16)` 底 + 1rpx `rgba(255,90,54,0.4)` 边 + `#FF8A6E` 字。
- 其余标签：`#26262C` 底 + `#A6A6AD` 字。
- 统一：24rpx，padding 8rpx 20rpx，圆角 999rpx，带类型图标 28rpx。

### 4.4 运营方行（条件显示）

```
┃ 运营方  XX滑板俱乐部                    ›
```

- 独立 chip 卡：`#17171B` 底 + **左侧 3rpx 橙色态度线** + 圆角 12rpx，padding 22rpx 24rpx。
- label「运营方」22rpx `#8C8C94`；名称 26rpx / 600 / `#FF8A6E`，单行截断；右箭头 `#8C8C94`。
- 点击进入 `shop-detail`。无运营方时整行不渲染。

### 4.5 报错入口（从操作栏迁入）

- 位置：信息卡**地址行行尾**（flex 末位；地址文字 `flex:1` 占满剩余宽度，长地址换行时自动避让，与距离 pill 不同行，绝不重叠）。
- 形态：旗图标 24rpx + 「报错」22rpx，均 `#6E6E76`，触控区 ≥64×64rpx，与地址首行垂直对齐。
- 点击打开报错 sheet。低频入口弱化为最浅文字色，不干扰决策行。

## 5. 今日打卡卡

容器：`background: #1E1E23; border-radius: 16rpx; margin: 24rpx 32rpx 0; padding: 28rpx 32rpx;` + **左侧 3rpx 竖线**（有打卡 `#FF5A36` / 无人 `#3A3A42`）。

> 语义变更：原「实时在场卡」改为**今日打卡人数**。打卡人数是热度数据，非「在场/在线」语义——不用绿色、不做脉冲动画；实时在场信息不再在前台任何页面展示。

### 5.1 今日有人打卡（todayCount > 0）

- 第一行（纯排版，无图标）：「今日」26rpx / `#8C8C94` + 数字 32rpx / 600 / `#FFFFFF` + 「位滑手打卡」26rpx / `#8C8C94`。句式与首页「今日 N 人打过卡」同源，场地级用「滑手」。
- 第二行：今日打卡滑手头像 ×4（72rpx 圆形，3rpx `#1E1E23` 描边，间距 -12rpx 叠放）+ 折叠「+N」灰圆；头像取自今日打卡记录。

### 5.2 今日无人打卡（todayCount = 0）

- 左侧竖线转灰 `#3A3A42`，整卡弱化。
- 文字：「今日还没滑手打卡」，26rpx / `#8C8C94`。
- 不显示头像行，不显示任何「快来第一个」之类的引导文案（内容克制）。

## 6. 打卡动态

### 6.0 设计决策：同一张卡，两个版本

打卡是同一份数据实体，发现页与详情页**骨架必须统一**（用户不应在两处看到两种长相的卡，认知与维护成本翻倍）；但两个页面的任务不同，**密度与交互按场景裁剪**：

| 元素 | 发现页 · 完整社区版 | 详情页 · 紧凑决策版 | 裁剪理由 |
|---|---|---|---|
| 容器 / 底色 / 圆角 | ✅ 相同 | ✅ 相同 | 同一实体 |
| 头像+昵称+滑龄+时间 | ✅ 相同排版 | ✅ 相同排版 | 认知一致 |
| 留言字号 / 行高 | ✅ 相同 | ✅ 相同（限 3 行） | 详情页密度 |
| 媒体九宫格规则（1/2/3+） | ✅ 相同 | ✅ 相同 | 同一规则 |
| 视频角标 / 上传中角标 | ✅ 相同 | ✅ 相同 | 同一规则 |
| 点击媒体行为 | 图→遮罩 / 视频→独立页 | 图→遮罩 / 视频→独立页 | 同一行为 |
| **场地胶囊** | ✅ 有（跳场地详情） | ❌ 无 | 已是当前场地，自指冗余，点了进自己 |
| **互动区（点赞/评论）** | ✅ 有 | ❌ 无 | 详情页操作焦点唯一（签到/导航/发打卡），再放互动入口会分散焦点、拉长页面；且仅展示 3 条，样本太小，互动数无参考意义 |
| 长按编辑（本人打卡） | ❌ | ✅ | 详情页同时是「我在此场的打卡管理」场景 |

**互动动线**：详情页紧凑卡 →「查看全部」进 `place-checkins`（完整版可互动）→ 或点卡片进 `post-detail`。点赞/评论在这两层发生，详情页只负责「看氛围」。

> 实现建议：打卡卡做成**同一组件的两个模式**（`mode: full | compact`），compact 模式不渲染场地胶囊与互动区，样式与排版规则完全共享，一处改两边生效。

### 6.1 标题行

- 「打卡动态」32rpx / 700 / `#FFFFFF`；右侧「查看全部 ›」28rpx / `#8C8C94`，进入 `place-checkins`。

### 6.2 打卡卡（compact 模式规格）

- 容器 `#1E1E23` 圆角 16rpx，padding 24rpx。
- 头像 72rpx 圆形；昵称 28rpx / 500 / `#FFFFFF`；滑龄 20rpx `#8A8A93`（昵称右侧）；时间 24rpx `#8C8C94`。
- 留言 28rpx / `#D9D9DE`，行高 1.6，最多 3 行。
- 媒体九宫格：1 张 320rpx 方图；2 张对半；≥3 张三列方格；视频带播放三角角标 + 「上传中」角标（本机临时视频）。
- 点击媒体：图片进 `media-viewer` 遮罩，视频进 `video-preview` 独立页（见 `MEDIA_VIEWER_DESIGN_SPEC.md` v1.5）。
- 点头像/昵称进 `user-profile`；长按本人打卡可编辑。
- **不渲染**：场地胶囊、点赞/评论互动区。

### 6.3 空态

- 无打卡：「还没有打卡，点下方「发打卡」发第一条」，26rpx / `#6E6E76`，居中，padding 40rpx 0。不配插画，保持轻。

## 7. 底部固定操作栏

### 7.1 布局（固定三键，键位不随签到状态跳动）

容器：fixed 底部，`rgba(17,17,20,0.96)` + 顶部分割线 `#26262C`，padding `20rpx 32rpx calc(20rpx + safe-area)`，gap 20rpx。

| 槽位 | 宽度 | 未签到态 | 已签到态 |
|---|---|---|---|
| 左 | 128rpx | 导航（深色方块） | 导航（深色方块） |
| 中 | flex | **签到**（橙渐变主键） | **发打卡**（橙渐变主键） |
| 右 | 128rpx | 发打卡（橙描边 ghost） | 已签到（绿描边 done） |

> 报错从此栏移除（迁入信息卡地址行行尾）。主键永远在中间最大位，肌肉记忆不被打断。

### 7.2 键位样式

| 键 | 规范 |
|---|---|
| 导航 | `#1E1E23` 底，圆角 20rpx，图标 40rpx + 「导航」22rpx，`#A6A6AD` |
| 主键（签到/发打卡） | `linear-gradient(135deg, #FF5A36, #FF8A6E)`，圆角 999rpx，高 96rpx，图标 40rpx + 文字 30rpx / 600 / 白，`box-shadow: 0 8rpx 24rpx rgba(255,90,54,0.3)` |
| 副键-发打卡 ghost | 透明底 + 2rpx `rgba(255,90,54,0.35)` 边，图标 + 「发打卡」22rpx，`#FF8A6E` |
| 副键-已签到 done | 透明底 + 2rpx `rgba(0,212,170,0.5)` 边，勾图标 + 「已签到」22rpx，`#00D4AA`；点击 toast「今日已签到」 |

### 7.3 行为

- **签到**：定位硬校验（`PRESENCE_RADIUS_M` 内才可签），成功 → 庆祝层（第 9 节），主键切换为发打卡。
- **导航**：调起系统地图导航到场地坐标。
- **发打卡**：未签到时点击 → toast「先签到，才能发打卡」+ 主键呼吸一次引导；已签到 → 打开发打卡 sheet。
- 快捷签到：`?checkin=1` 进入页面自动触发签到（保留现有能力）。

## 8. 弹层（全部底部 sheet，形态统一）

统一容器：底部 sheet，`#232329` + 顶部 1rpx `#2F2F36`，圆角 32rpx 32rpx 0 0，顶部把手 72×8rpx `#3A3A42`，max-height 86vh。遮罩 `rgba(0,0,0,0.6)`，点击遮罩关闭。入场 250ms ease-out 滑入。

### 8.1 发打卡 sheet（维持现状，仅对齐视觉）

- 头部：橙圆相机徽章 + 「发布打卡/编辑打卡」36rpx + 关闭 ×。
- 场地 chip（pin + 场地名）。
- 留言 textarea（200 字，计数）。
- 媒体区：图 ≤9 / 视频 1 个互斥；视频态独占大格 + 时长角标。
- 提交：橙渐变胶囊 96rpx；取消：文字按钮。

### 8.2 报错 sheet（维持现状结构）

- 头部：旗图标 + 「场地报错」+ 关闭 ×。
- 问题类型 chips（选中态橙）。
- 描述 textarea（500 字必填，错误红边 + 抖动 250ms）。
- 举证照片 ≤3 张。
- 提交：橙渐变胶囊。

### 8.3 评分 sheet（新增，替代原居中卡片）

```
┌─────────────────────────┐
│         ───（把手）      │
│  给「南湖广场」评分       │
│  你当前评分 4 星（条件）   │
│   ★  ★  ★  ★  ★       │
│       4 星              │
│  ┌───── 提交评分 ─────┐  │
└─────────────────────────┘
```

- 标题 32rpx / 700；已评过显示「你当前评分 N 星，点击星星可修改」24rpx `#8C8C94`。
- 五颗大星 80rpx，间距 20rpx，选中橙色 + scale(1.1) 150ms。
- 状态文字：未选「点击评分」/ 已选「N 星」，26rpx `#A6A6AD`。
- 提交：橙渐变胶囊 96rpx；未选星时点击 toast「请先点亮星星」。
- 提交成功：toast「评分成功」+ 关闭 sheet + 刷新评分行。

## 9. 签到庆祝层（瘦身版）

> 原版的徽章激励文案（「再打 N 天解锁」）、彩纸雨、2.6s 强制停留全部废止——违反内容克制与轻量化原则。

### 9.1 结构

```
遮罩 rgba(0,0,0,0.55)（点击即关）
└── 卡片 #1E1E23，宽 480rpx，圆角 32rpx，padding 48rpx 44rpx
    ├── 徽章：104rpx 橙渐变圆 + 白勾 52rpx（保留 6rpx 橙描边环）
    ├── 「签到成功」38rpx / 700 / #FFFFFF
    └── 「已连续签到 N 天」28rpx / 600 / #00D4AA
```

### 9.2 动效与时长（全部 ≤250ms）

- 入场：遮罩 opacity 0→1（150ms）+ 卡片 opacity 0→1 & scale 0.9→1（200ms ease-out）。
- 消失：1.2s 后自动淡出 200ms；点击遮罩立即关闭。
- **禁止**：彩纸、光晕、弹性过冲（cubic-bezier 1.56）、徽章里程碑文案、第三方跳转引导。

### 9.3 内容纪律

只反馈真实数据：签到成功 + 连续天数。N 来自真实连续签到统计。无其他文案。

## 10. 状态规则汇总

| 状态 | 规则 |
|---|---|
| 未签到 | 主键=签到；副键=发打卡 ghost（点击 toast 引导先签到） |
| 已签到 | 主键=发打卡；副键=已签到 done（点击 toast「今日已签到」） |
| 无图 | 头图区显示线稿占位（禁死黑块） |
| 无评分 | 评分行显示灰色五星 + 「暂无」，点击仍可评 |
| 今日无人打卡 | 今日打卡卡弱化（灰线灰字），无头像行 |
| 无打卡 | 打卡动态区显示空态一行 |
| 无运营方 | 运营方行不渲染 |
| 无距离权限 | 距离 pill 隐藏，地址行独占 |
| 本周来滑 ≥10 | 头图名称右侧显示「本周 N 人来滑」倾斜贴纸 |

## 11. 与 shop-detail 的复用关系

`shop-detail`（板店/俱乐部/培训机构详情）复用本规范全部规则，仅以下差异：

- 机构详情同用「本周 N 人来滑」贴纸，条件可由业务定义（无则不显示）。
- 今日打卡卡在机构详情替换为「营业状态卡」：左绿线 = 营业中「现在营业 · 至 21:00」；灰线 = 休息中「休息中 · 明天 10:00 开门」。绿色语义不变。
- 操作栏主键：机构无签到，主键 = 「导航」或「联系」，副键按业务配置；但**布局槽位、键位样式、弹层形态不变**。
- 打卡动态区：机构可挂「场地动态」（其运营场地的打卡聚合），无则不显示。

## 13. 禁止项

- 庆祝层禁止出现激励/里程碑文案、彩纸、强制停留 >1.5s。
- 头图右侧（胶囊区下方垂直带）禁止放任何按钮。
- 绿色禁止用于「在场/已签到/营业中」以外元素。
- 标签禁止超过 3 个平铺（必须折叠 +N）。
- 操作栏禁止出现第 4 个键；键位禁止随状态改变位置。
- 空态/无数据处禁止出现营销式引导文案。
- 弹层禁止再出现居中卡片形态（全部底部 sheet）。
