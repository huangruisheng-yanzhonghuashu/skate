# 去哪滑 · 发现页内容预览设计规范 v1.0

> 本规范针对 去哪滑 微信小程序「发现」页中点击图片 / 视频后进入的全屏内容预览（media-viewer）。是发现页视觉系统的延伸，承接 feed 卡片的街头、沉浸、克制动效。

---

## 1. 设计前提

### 1.1 继承关系

预览层是发现页 feed 的「放大态」，必须延续同一套视觉语言：

- 背景：纯黑 `#000000`（内容预览需要全屏沉浸，不能用发现页背景灰）
- 品牌色：`#FF5A36`（橙），用于当前分页点、播放按钮 hover、加载失败提示
- 辅助色：`#FF8A6E`
- 文字：`#FFFFFF` 为主，`rgba(255,255,255,0.7)` 为次级
- 字体：系统默认字体
- 微动效：≤250ms

### 1.2 使用场景

1. 用户在发现页点击 feed 卡片中的图片或视频封面。
2. 进入全屏预览，保持当前所在媒体位置，可左右滑动浏览该条打卡的全部媒体。
3. 关闭后回到发现页，底部 TabBar 恢复显示。

## 2. 内容预览层级

```
全屏遮罩（bg #000，z-index 9999）
├── 顶部状态栏占位 + 安全区
├── 关闭按钮（右上角，白色 ×）
├── 媒体轮播层（swiper）
│   ├── 图片项：image mode="aspectFit"，点击关闭
│   ├── 视频项：
│   │   ├── 未播放：封面图 + 播放按钮（白色三角 + 半透明圆底）
│   │   └── 播放中：原生 video controls，自动播放
│   └── 左右滑动切换
├── 顶部计数器（当前 / 总数，仅多图时显示）
├── 底部分页指示器（圆点，当前橙色，其余半透明白）
└── 加载失败占位（若媒体加载失败）
```

## 3. 视觉规范

### 3.1 全屏遮罩

```
position: fixed
left: 0; top: 0; right: 0; bottom: 0
background: #000000
z-index: 9999
```

### 3.2 顶部关闭按钮

```
位置：右上角
right: 30rpx
top: calc(40rpx + env(safe-area-inset-top))
尺寸：64rpx × 64rpx
图标：白色 ×，线宽 4rpx，线长 44rpx，圆角 2rpx
触控区：保证 88rpx × 88rpx 热区
```

### 3.3 顶部计数器（多图时显示）

```
位置：顶部居中，与关闭按钮同一行
 top: calc(44rpx + env(safe-area-inset-top))
字体：28rpx，color rgba(255,255,255,0.9)，font-weight 500
格式：「3 / 8」
```

### 3.4 媒体轮播层

```
宽度：100%
高度：100%
图片：mode="aspectFit"，不裁剪，居中显示
```

### 3.5 视频未播放态

```
视频容器：100% × 100%
封面图：object-fit: cover
播放按钮：
  - 尺寸：112rpx × 112rpx
  - 背景：rgba(17,17,20,0.55)
  - 圆角：999rpx
  - backdrop-filter: blur(8rpx)
  - 三角：白色，border-left 34rpx，border-top/bottom 22rpx
```

### 3.6 视频播放态

```
video 标签：
  - width: 100%; height: 100%
  - object-fit: contain
  - controls: true
  - autoplay: true
切换 swiper 时自动停止播放中的视频
```

### 3.7 底部分页指示器

```
位置：底部居中
bottom: calc(60rpx + env(safe-area-inset-bottom))
点尺寸：8rpx × 8rpx（当前 10rpx × 10rpx）
点间距：16rpx
未选中：rgba(255,255,255,0.35)
当前：#FF5A36
圆角：999rpx
```

### 3.8 加载失败占位

```
容器：居中显示
图标：图片裂图占位（可用 48rpx 橙色）
文案：「图片加载失败」
字体：26rpx，color rgba(255,255,255,0.6)
```

## 4. 交互规则

1. **点击进入预览**：发现页点击 feed 卡片媒体区 → 打开 viewer，当前 index 为被点击媒体的 index。
2. **隐藏 TabBar**：预览打开期间隐藏底部 TabBar（调用 custom-tab-bar 的 hidden）。
3. **左右滑动**：单指左右滑动切换下一张 / 上一张；切换时停止当前播放中的视频（playingIdx 归位）。
4. **关闭预览**：点击右上角 ×、或点击图片（图片项）关闭。关闭后恢复 TabBar。
5. **视频播放**：视频项点击播放按钮后进入播放态，自动播放；再次点击播放中的视频不处理（原生 controls 接管）。
6. **视频切换**：从视频项滑走时，该视频停止播放。
7. **单张不显示分页器**：sources.length === 1 时隐藏计数器和底部分页点。
8. **返回键**：监听页面返回事件？小程序组件内无法直接监听返回键，因此依赖关闭按钮 / 点击关闭。

---

## 5. 动效

- 打开：无淡入（直接全屏黑底，内容 0.15s opacity 0→1）。
- 切换：swiper 原生滑动，300ms。
- 播放按钮点击：0.1s scale 0.9→1.1→1.0 脉冲。
- 关闭：0.15s opacity 淡出。

---

## 6. 禁止项

- 视频不自动播放，必须用封面 + 播放按钮。
- 不显示标题栏，保持全屏沉浸。
- 不使用橙色以外的强调色做当前指示。
- 不添加下载 / 收藏 / 分享等额外操作，保持预览纯粹。

---

## 7. 数据规范

sources 结构：

```js
[
  { type: 'image', url: 'cloud://...' },
  { type: 'video', url: 'cloud://...', cover: 'cloud://...' },
  ...
]
```

current：初始显示第几个，从 0 开始。
