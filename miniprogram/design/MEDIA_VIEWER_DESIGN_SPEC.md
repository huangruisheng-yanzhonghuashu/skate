# 去哪滑 · 发现页内容预览设计规范 v1.4

> 本规范针对 去哪滑 微信小程序「发现」页点击图片 / 视频后进入的全屏内容预览。只定义 UI 与交互，不进入代码实现。
> 交互参考微博小程序：图片点击关闭；视频预览通过系统返回 / 左滑退出，右下角浮出「点赞 / 评论 / 转发」操作按钮。

---

## 1. 设计前提

### 1.1 继承关系

预览层是发现页 feed 的「放大态」，延续同一套视觉语言：

- 背景：纯黑 `#000000`
- 品牌色：`#FF5A36`（橙），用于已点赞态、当前分页点、可发送态
- 辅助色：`#FF8A6E`
- 文字：`#FFFFFF` 为主，`rgba(255,255,255,0.7)` 为次级
- 字体：系统默认字体
- 微动效：≤250ms

### 1.2 内容范围

发现页打卡只产生两类媒体：

- **视频**：一条打卡最多 **1 条视频**
- **图片**：一条打卡最多 **9 张图片**

预览组件处理两种独立状态：

- `video`：单视频全屏预览
- `image`：1–9 张图片滑动预览

### 1.3 顶部禁止原则

顶部不放置任何自定义按钮（关闭、返回、完成等），避免与微信小程序系统胶囊按钮 / 返回区冲突。

## 2. 图片预览

### 2.1 层级

```
全屏遮罩（bg #000）
├── 顶部状态栏占位
├── 顶部居中计数器（多图时显示）
├── 图片轮播层（swiper）
│   └── 图片项：aspectFit，点击关闭
└── 底部分页指示器（圆点，多图时显示）
```

### 2.2 视觉规范

| 元素 | 规范 |
|---|---|
| 遮罩 | `#000000`，fixed 全屏，z-index 9999 |
| 计数器 | 顶部居中，top: calc(44px + env(safe-area-inset-top))，28rpx，rgba(255,255,255,0.9) |
| 图片 | width 100%，height 100%，mode="aspectFit" |
| 分页圆点 | 底部居中，bottom: calc(60rpx + env(safe-area-inset-bottom))，6rpx/10rpx，当前橙色 |

### 2.3 交互

- 点击图片任意区域关闭预览。
- 左右滑动切换上一张 / 下一张。
- 单张图片时隐藏计数器和圆点。

## 3. 视频预览

### 3.1 层级

```
全屏遮罩（bg #000）
├── 顶部状态栏占位
├── 视频层
│   ├── 未播放：封面图 + 居中播放按钮
│   └── 播放中：原生 video controls
└── 右下角操作按钮组（fixed）
    ├── 点赞（心形）
    ├── 评论（气泡 + 数量）
    └── 转发（分享）
```

### 3.2 视觉规范

#### 视频封面/播放态

| 元素 | 规范 |
|---|---|
| 封面 | 100% × 100%，object-fit: cover |
| 播放按钮 | 112rpx 圆形，bg rgba(17,17,20,0.55)，backdrop-filter blur(8rpx) |
| 播放三角 | 白色实心，宽 34rpx，高 22rpx |
| 播放中 video | 100% × 100%，object-fit: contain，controls |

#### 右下角操作按钮组

```
位置：fixed
right: 32rpx
bottom: calc(120rpx + env(safe-area-inset-bottom))
排列：竖排，gap 24rpx
按钮尺寸：96rpx × 96rpx
按钮背景：rgba(30,30,35,0.72)
按钮边框：1rpx solid rgba(255,255,255,0.08)
按钮圆角：999rpx
图标尺寸：40rpx
图标颜色：#FFFFFF
```

三个按钮从上至下：

1. **点赞**：心形
   - 未点赞：空心，stroke #FFFFFF
   - 已点赞：实心，fill #FF5A36，stroke #FF5A36
2. **评论**：气泡图标 + 评论数
   - 图标：空心气泡，stroke #FFFFFF
   - 数量：图标下方 20rpx，#FFFFFF，22rpx
   - 数量为 0 时隐藏数字，只显示气泡图标
3. **转发**：分享/转发图标，白色

### 3.3 交互

- 封面状态：点击播放按钮开始播放；点击操作按钮执行对应操作。
- 播放状态：video controls 接管播放控制；右下角操作按钮始终悬浮在最上层。
- 关闭：通过系统返回键 / 手机左侧滑动手势退出，与首页场地详情返回方式一致。预览层内部不放置关闭按钮。
- 点赞：点击右下角「点赞」按钮，本地即时反馈 + 触发点赞动画。
- 评论：点击右下角「评论」按钮，从底部拉起半屏评论面板。
- 转发：点击右下角「转发」按钮，触发 `onShareAppMessage` / 生成海报（由业务层决定）。

## 4. 评论面板（视频预览内）

### 4.1 触发与定位

- 触发：视频预览中点击右下角「评论」按钮。
- 形态：从底部弹起的半屏面板（bottom-sheet），覆盖在视频预览层之上。
- 默认高度：屏幕高度的 **60%**（约 486rpx）。
- 可拖拽：手指按住顶部把手可上拉至 **80%**，下拉可收回。
- 背景遮罩：`rgba(0,0,0,0.55)`，点击遮罩关闭面板。

### 4.2 层级

```
评论面板层（z-index 高于视频预览）
├── 遮罩（点击关闭）
└── 半屏面板
    ├── 顶部把手 + 标题「N 条评论」+ 关闭按钮（×）
    ├── 评论列表（可滚动）
    │   └── 评论项：头像 / 昵称 / 时间 / 内容 / 点赞
    └── 底部输入区
        ├── 输入框「说点什么…」
        └── 发送按钮
```

### 4.3 视觉规范

#### 面板容器

| 元素 | 规范 |
|---|---|
| 背景 | `#1E1E23` |
| 顶部圆角 | 32rpx |
| 顶部把手 | 宽 72rpx，高 6rpx，圆角 3rpx，颜色 rgba(255,255,255,0.25)，居中对齐 |
| 标题 | 「128 条评论」，32rpx，#FFFFFF，font-weight 600 |
| 关闭按钮 | 右侧 24rpx，44×44rpx 触控区，白色 × |
| 面板内边距 | 左右 28rpx，顶部 20rpx |

#### 评论列表项

| 元素 | 规范 |
|---|---|
| 头像 | 64rpx 圆形，默认占位图 #2A2A30 |
| 昵称 | 28rpx，#FFFFFF，font-weight 500 |
| 时间 | 22rpx，rgba(255,255,255,0.5) |
| 内容 | 28rpx，rgba(255,255,255,0.9)，行高 1.5 |
| 点赞区 | 右侧 24rpx 对齐，心形 28rpx + 数量 22rpx |
| 已点赞 | 心形 fill #FF5A36，数字 #FF5A36 |
| 未点赞 | 心形 stroke rgba(255,255,255,0.6)，数字 rgba(255,255,255,0.5) |
| 项间距 | 相邻评论项间距 32rpx |
| 回复楼中楼 | 暂不实现深层嵌套；点击评论项可在输入框 @ 该用户 |

#### 底部输入区

| 元素 | 规范 |
|---|---|
| 容器高度 | 固定 112rpx，背景 #1E1E23 |
| 上边框 | 1rpx solid rgba(255,255,255,0.08) |
| 输入框 | 高度 72rpx，背景 #111114，圆角 999rpx，内边距 0 28rpx |
| 占位文字 | 「说点什么…」，26rpx，rgba(255,255,255,0.45) |
| 发送按钮 | 右侧 28rpx，文字「发送」，30rpx |
| 发送按钮-未输入 | 颜色 rgba(255,255,255,0.35)，不可点击 |
| 发送按钮-有内容 | 颜色 #FF5A36，可点击 |
| 键盘适配 | 输入框随键盘高度上移，贴键盘顶部 |

### 4.4 交互

- 打开：面板从底部 translateY(100%) → translateY(0)，0.25s ease-out；遮罩 opacity 0 → 0.55。
- 关闭：点击遮罩 / 点击关闭按钮 / 下拉把手至阈值；面板下沉，遮罩淡出。
- 上拉：拖拽顶部把手，面板高度从 60% 展开至 80%。
- 列表滚动：列表独立滚动，不影响底层视频。
- 点击评论项：输入框 focus，并在内容前自动插入 `@昵称 `（可删除）。
- 点击点赞（评论）：本地即时变橙 + 数字 +1，失败回滚。
- 发送评论：按钮进入 loading，成功后新评论插入列表顶部，输入框清空并显示「评论已发布」Snackbar；失败提示重试。
- 空态：评论数为 0 时，列表区域居中显示「暂无评论，来说点什么吧」，26rpx，rgba(255,255,255,0.45)。

## 5. 两种状态对比

| 维度 | 图片预览 | 视频预览 |
|---|---|---|
| 数量 | 1–9 张 | 1 条 |
| 顶部 | 多图时显示计数器 | 不显示任何内容 |
| 底部 | 多图时显示分页圆点 | 不显示分页圆点 |
| 关闭方式 | 点击图片任意区域 | 系统返回 / 左侧滑回 |
| 操作按钮 | 无 | 右下角「点赞 / 评论 / 转发」 |
| 评论入口 | 无 | 点击评论按钮拉起半屏评论面板 |
| 滑动切换 | 支持 | 不支持（单条） |

---

## 6. 动效

- 打开：内容 0.15s opacity 0→1。
- 切换：swiper 原生滑动 300ms。
- 播放按钮点击：0.1s scale 0.95→1.0 脉冲。
- 点赞：0.15s scale 1.25 回弹 + 0.35s 心脏爆开。
- 关闭：0.15s opacity 淡出。
- 评论面板打开：0.25s ease-out 从底部滑入。
- 评论面板关闭：0.2s ease-in 向下滑出。
- 评论发送成功：新评论 0.2s 从顶部滑入。

---

## 7. 禁止项

- 顶部不放关闭 / 返回 / 完成按钮。
- 视频预览内部不放置关闭按钮，统一走系统返回。
- 图片状态不放右下角操作按钮（与微博一致，点击即关）。
- 不使用橙色以外的强调色。
- 评论面板不在顶部放自定义返回按钮，关闭靠把手下拉 / 点击遮罩 / 关闭 ×。

## 8. 数据规范

```js
// 图片状态
[
  { type: 'image', url: 'cloud://...' },
  ...
]

// 视频状态（仅一条）
[
  { type: 'video', url: 'cloud://...', cover: 'cloud://...' }
]

// 评论项
{
  id: 'comment_id',
  userId: 'user_id',
  avatar: 'cloud://...',
  nickname: '滑手昵称',
  content: '评论内容',
  createTime: 1725667200000,
  likeCount: 12,
  liked: false
}
```

current：初始显示第几个，从 0 开始。

## 9. 实现提示

- 预览组件接受 `sources`、`current`、`visible`、`liked`、`commentCount` 五个属性。
- 视频播放期间，右下角按钮组需要 `z-index` 高于 video 组件。
- 图片 preview 的 swiper 使用 `catchtap` 在图片项上绑定关闭，避免与滑动冲突。
- 点赞状态由父页面传入，组件内只做视觉反馈并 `triggerEvent('like')`。
- 评论按钮点击触发 `triggerEvent('comment')`，由父页面拉起评论面板。
- 评论面板建议作为独立子组件 `comment-panel`，接收 `visible`、`comments`、`count` 属性，通过 `bind:send` 抛出发送事件。
- 输入框使用 `textarea` 或 `input` 的 `adjust-position` / `hold-keyboard` 处理键盘弹起；复杂场景可用 `wx.onKeyboardHeightChange` 手动计算。
