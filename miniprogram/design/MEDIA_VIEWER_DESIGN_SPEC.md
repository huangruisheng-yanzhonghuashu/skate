# 去哪滑 · 发现页内容预览设计规范 v1.5

> 本规范针对 去哪滑 微信小程序「发现」页点击图片 / 视频后的内容预览。只定义 UI 与交互，不进入代码实现。
> **图片预览**：页面内全屏遮罩，点击图片任意区域关闭。
> **视频预览**：独立详情页面（navigateTo 跳转，与首页列表进入场地详情一致），导航栏左侧返回按钮 + 右滑手势返回，右下角浮出「点赞 / 评论 / 转发」操作按钮。

---

## 1. 设计前提

### 1.1 继承关系

预览层是发现页 feed 的「放大态」，延续同一套视觉语言：

- 背景：纯黑 `#000000`
- 品牌色：`#FF5A36`（橙），用于已点赞态、当前分页点、可发送态
- 辅助色：`#FF8A6E`
- 文字：`#FFFFFF` 为主，`rgba(255,255,255,0.7)` 为次级
- 字体：系统默认字体
- 微动效：≤250ms

### 1.2 内容范围与载体

发现页打卡只产生两类媒体：

- **视频**：一条打卡最多 **1 条视频**
- **图片**：一条打卡最多 **9 张图片**

两类媒体采用不同的预览载体：

| 媒体 | 载体 | 页面类型 | 返回方式 |
|---|---|---|---|
| 视频 | **独立页面** `video-preview`（navigateTo） | 与场地详情页同级 | 导航栏返回按钮 / 右滑手势 |
| 图片 | **页面内遮罩** `media-viewer` 组件 | 发现页上的浮层 | 点击图片任意区域 |

> 为什么视频用独立页面：视频有播放状态、评论面板等重交互，独立页面有完整的生命周期与系统导航返回能力（右滑返回手势），体验与首页→场地详情一致；同时避免在遮罩内自绘返回按钮与右上角胶囊冲突。

### 1.3 胶囊避让原则

- 视频预览页导航栏**右侧为系统胶囊保留区**，不放任何自定义按钮。
- 自定义导航栏内容只放**左侧返回按钮**。
- 图片遮罩顶部不放置任何自定义按钮。

## 2. 图片预览（页面内遮罩）

### 2.1 层级

```
全屏遮罩（bg #000，在发现页内）
├── 顶部状态栏占位
├── 顶部居中计数器（多图时显示）
├── 图片轮播层（swiper）
│   └── 图片项：aspectFit，点击关闭
└── 底部分页指示器（圆点，多图时显示）
```

### 2.2 视觉规范

| 元素 | 规范 |
|---|---|
| 遮罩 | `#000000`，fixed 全屏，z-index 9999 |
| 计数器 | 顶部居中，top: calc(44px + env(safe-area-inset-top))，28rpx，rgba(255,255,255,0.9) |
| 图片 | width 100%，height 100%，mode="aspectFit" |
| 分页圆点 | 底部居中，bottom: calc(60rpx + env(safe-area-inset-bottom))，6rpx/10rpx，当前橙色 |

### 2.3 交互

- 点击图片任意区域关闭预览。
- 左右滑动切换上一张 / 下一张。
- 单张图片时隐藏计数器和圆点。

## 3. 视频预览（独立详情页面）

### 3.1 页面结构

```
独立页面 video-preview（navigationStyle: custom，背景 #000）
├── 自定义导航栏（透明背景，浮于视频之上）
│   ├── 左侧：返回按钮（白色 ←，44×44pt 触控区）
│   └── 右侧：系统胶囊保留区（不放内容）
├── 视频层（全屏）
│   ├── 未播放：封面图 + 居中播放按钮
│   └── 播放中：原生 video controls
└── 右下角操作按钮组（fixed）
    ├── 点赞（心形）
    ├── 评论（气泡 + 数量）
    └── 转发（分享）
```

### 3.2 视觉规范

#### 自定义导航栏

| 元素 | 规范 |
|---|---|
| 容器 | 高度 = 状态栏 + 44px，透明背景，fixed 顶部，z-index 100 |
| 返回按钮 | 左侧 16rpx，88×88rpx 触控区；白色 ← 箭头，40rpx |
| 背景 | 默认透明（内容即氛围） |
| 右侧 | 系统胶囊保留区，禁止放任何元素 |

#### 视频封面/播放态

| 元素 | 规范 |
|---|---|
| 封面 | 100% × 100%，object-fit: cover |
| 播放按钮 | 112rpx 圆形，bg rgba(17,17,20,0.55)，backdrop-filter blur(8rpx) |
| 播放三角 | 白色实心，宽 34rpx，高 22rpx |
| 播放中 video | 100% × 100%，object-fit: contain，controls |

#### 右下角操作按钮组

```
位置：fixed
right: 32rpx
bottom: calc(120rpx + env(safe-area-inset-bottom))
排列：竖排，gap 24rpx
按钮尺寸：96rpx × 96rpx
按钮背景：rgba(30,30,35,0.72)
按钮边框：1rpx solid rgba(255,255,255,0.08)
按钮圆角：999rpx
图标尺寸：40rpx
图标颜色：#FFFFFF
```

三个按钮从上至下：

1. **点赞**：心形
   - 未点赞：空心，stroke #FFFFFF
   - 已点赞：实心，fill #FF5A36，stroke #FF5A36
2. **评论**：气泡图标 + 评论数
   - 图标：空心气泡，stroke #FFFFFF
   - 数量：图标下方 20rpx，#FFFFFF，22rpx
   - 数量为 0 时隐藏数字，只显示气泡图标
3. **转发**：分享/转发图标，白色

### 3.3 交互

- **进入**：发现页点击视频 → `wx.navigateTo` 打开 `video-preview`，页面右滑入。
- **返回**：三种方式，与首页场地详情页一致
  1. 点击导航栏左侧返回按钮
  2. iOS 右滑手势（页面左边缘向右滑动）
  3. Android 系统返回键
- **播放**：封面状态点击播放按钮开始播放；播放中 video controls 接管播放控制；右下角操作按钮始终悬浮在最上层。
- **点赞**：点击右下角「点赞」按钮，本地即时反馈 + 触发点赞动画。
- **评论**：点击右下角「评论」按钮，从底部拉起半屏评论面板（见第 4 节）。
- **转发**：点击右下角「转发」按钮，触发 `onShareAppMessage` / 生成海报（由业务层决定）。
- **状态同步**：返回发现页时，点赞数 / 评论数同步回写到对应 feed 项。

## 4. 评论面板（视频预览页内）

### 4.1 触发与定位

- 触发：视频预览页中点击右下角「评论」按钮。
- 形态：从底部弹起的半屏面板（bottom-sheet），覆盖在视频预览页之上。
- 默认高度：屏幕高度的 **60%**。
- 可拖拽：手指按住顶部把手可上拉至 **80%**，下拉可收回。
- 背景遮罩：`rgba(0,0,0,0.55)`，点击遮罩关闭面板。

### 4.2 层级

```
评论面板层（z-index 高于视频与操作按钮组）
├── 遮罩（点击关闭）
└── 半屏面板
    ├── 顶部把手 + 标题「N 条评论」+ 关闭按钮（×）
    ├── 评论列表（可滚动）
    │   └── 评论项：头像 / 昵称 / 时间 / 内容 / 点赞
    └── 底部输入区
        ├── 输入框「说点什么…」
        └── 发送按钮
```

### 4.3 视觉规范

#### 面板容器

| 元素 | 规范 |
|---|---|
| 背景 | `#1E1E23` |
| 顶部圆角 | 32rpx |
| 顶部把手 | 宽 72rpx，高 6rpx，圆角 3rpx，颜色 rgba(255,255,255,0.25)，居中对齐 |
| 标题 | 「128 条评论」，32rpx，#FFFFFF，font-weight 600 |
| 关闭按钮 | 右侧 24rpx，44×44rpx 触控区，白色 × |
| 面板内边距 | 左右 28rpx，顶部 20rpx |

#### 评论列表项

| 元素 | 规范 |
|---|---|
| 头像 | 64rpx 圆形，默认占位图 #2A2A30 |
| 昵称 | 28rpx，#FFFFFF，font-weight 500 |
| 时间 | 22rpx，rgba(255,255,255,0.5) |
| 内容 | 28rpx，rgba(255,255,255,0.9)，行高 1.5 |
| 点赞区 | 右侧 24rpx 对齐，心形 28rpx + 数量 22rpx |
| 已点赞 | 心形 fill #FF5A36，数字 #FF5A36 |
| 未点赞 | 心形 stroke rgba(255,255,255,0.6)，数字 rgba(255,255,255,0.5) |
| 项间距 | 相邻评论项间距 32rpx |
| 回复楼中楼 | 暂不实现深层嵌套；点击评论项可在输入框 @ 该用户 |

#### 底部输入区

| 元素 | 规范 |
|---|---|
| 容器高度 | 固定 112rpx，背景 #1E1E23 |
| 上边框 | 1rpx solid rgba(255,255,255,0.08) |
| 输入框 | 高度 72rpx，背景 #111114，圆角 999rpx，内边距 0 28rpx |
| 占位文字 | 「说点什么…」，26rpx，rgba(255,255,255,0.45) |
| 发送按钮 | 右侧 28rpx，文字「发送」，30rpx |
| 发送按钮-未输入 | 颜色 rgba(255,255,255,0.35)，不可点击 |
| 发送按钮-有内容 | 颜色 #FF5A36，可点击 |
| 键盘适配 | 输入框随键盘高度上移，贴键盘顶部 |

### 4.4 交互

- 打开：面板从底部 translateY(100%) → translateY(0)，0.25s ease-out；遮罩 opacity 0 → 0.55。
- 关闭：点击遮罩 / 点击关闭按钮 / 下拉把手至阈值；面板下沉，遮罩淡出。
- 上拉：拖拽顶部把手，面板高度从 60% 展开至 80%。
- 列表滚动：列表独立滚动，不影响底层视频。
- 点击评论项：输入框 focus，并在内容前自动插入 `@昵称 `（可删除）。
- 点击点赞（评论）：本地即时变橙 + 数字 +1，失败回滚。
- 发送评论：按钮进入 loading，成功后新评论插入列表顶部，输入框清空并显示「评论已发布」Snackbar；失败提示重试。
- 空态：评论数为 0 时，列表区域居中显示「暂无评论，来说点什么吧」，26rpx，rgba(255,255,255,0.45)。
- 面板打开时遮罩覆盖全屏（含导航栏），先关闭面板再返回页面。

## 5. 两种预览对比

| 维度 | 图片预览（遮罩） | 视频预览（独立页面） |
|---|---|---|
| 数量 | 1–9 张 | 1 条 |
| 载体 | 发现页内全屏遮罩 | navigateTo 独立页面 |
| 顶部 | 多图时显示计数器 | 导航栏：左侧返回按钮，右侧胶囊保留区 |
| 底部 | 多图时显示分页圆点 | 不显示分页圆点 |
| 返回方式 | 点击图片任意区域 | 返回按钮 / 右滑手势 / 系统返回键 |
| 操作按钮 | 无 | 右下角「点赞 / 评论 / 转发」 |
| 评论入口 | 无 | 点击评论按钮拉起半屏评论面板 |
| 滑动切换 | 支持 | 不支持（单条） |

## 6. 动效

- 视频页面进入：navigateTo 原生右滑入（约 300ms）。
- 视频页面返回：navigateBack 原生左滑出。
- 图片遮罩打开：0.15s opacity 0→1；关闭 0.15s 淡出。
- 图片切换：swiper 原生滑动 300ms。
- 播放按钮点击：0.1s scale 0.95→1.0 脉冲。
- 点赞：0.15s scale 1.25 回弹 + 0.35s 心脏爆开。
- 评论面板打开：0.25s ease-out 从底部滑入；关闭 0.2s ease-in 向下滑出。
- 评论发送成功：新评论 0.2s 从顶部滑入。

---

## 7. 禁止项

- 视频预览页导航栏右侧（胶囊保留区）不放任何元素。
- 视频预览页不放置「完成」按钮，返回走导航栏按钮 / 系统手势。
- 图片遮罩状态不放右下角操作按钮（与微博一致，点击即关）。
- 图片遮罩顶部不放关闭 / 返回按钮。
- 不使用橙色以外的强调色。

## 9. 实现提示

- **视频预览页** `pages/video-preview/video-preview`：
  - `navigationStyle: custom`，页面背景 `#000`。
  - 导航栏自行实现：左侧返回按钮调用 `wx.navigateBack()`；右侧预留胶囊空间（通过 `wx.getMenuButtonBoundingClientRect()` 计算）。
  - 页面参数通过 URL query 传 `postId`，页面内自行拉取视频地址 / 点赞 / 评论数据，避免 URL 传超长 cloud:// 路径。
  - 返回时通过 `getCurrentPages()` 回写发现页 feed 项的 likeCount / commentCount，或由发现页 onShow 时刷新对应项。
- **图片遮罩** `media-viewer` 组件：保留现状，swiper 使用 `catchtap` 在图片项上绑定关闭，避免与滑动冲突。
- **评论面板**：建议作为独立组件 `comment-panel`，接收 `visible`、`comments`、`count` 属性，通过 `bind:send` 抛出发送事件；视频预览页与帖子详情页可复用。
- 输入框使用 `adjust-position` / `hold-keyboard` 处理键盘弹起；复杂场景可用 `wx.onKeyboardHeightChange` 手动计算。
- 视频播放期间，右下角按钮组与导航栏需要 `z-index` 高于 video 组件（原生 video 层级问题可用 cover-view 或播放时隐藏按钮组，优先 cover-view 方案验证）。
