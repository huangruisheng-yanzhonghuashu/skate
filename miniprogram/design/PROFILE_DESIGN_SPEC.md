# 去哪滑 · 我的页设计规范 v2.0

> 本规范定义微信小程序「我的」Tab 页（`pages/profile`）的信息架构、视觉与交互。
>
> 依据：`DESIGN_SPEC.md` v1.0（街头、自由、年轻、活力）+ 产品规则（签到入口只在场所详情、顶部不放全局签到 CTA、内容克制）。
>
> **v2 说明**：v1 只是「去重标题 + 加描边 + 合并行」，出来的仍是标准设置页，违背规范 2.6「不因大众化而变成中性模板」。v2 推倒重来：把首页品牌基因带进我的页——**斜体大字标「档案」+ 滑手 ID 卡（顶部橙条）+ 无卡数据带 + 贴纸式标签**，让这页看起来像一张「滑手的身份牌」，而不是系统设置。

---

## 1. 设计前提

### 1.1 我的页的任务

「我的」是用户在 去哪滑 的**身份牌与数据出口**。用户进来只有三件事：

1. **确认身份**：我是谁（头像、昵称、城市、滑龄、风格）。
2. **确认轨迹**：我滑了多少（签到 / 打卡 / 推荐）。
3. **管理出口**：我的历史内容 + 编辑资料。

页面气质 = **街头身份牌（Rider Pass）**：自信、直接、有态度，不是「个人中心功能列表」。

### 1.2 继承的视觉语言

- 页面底 `--bg` `#111114`，卡片 `--card` `#1E1E23` + 1rpx 描边 `--line` `#26262C`。
- 品牌橙 `#FF5A36`：ID 卡顶部橙条、头像环、签到数字、贴纸描边、编辑箭头。
- 语义绿 `#00D4AA`：我的页**不使用**（无在场/已签到语义场景）。
- 字体：系统字体栈；大字标与昵称统一 italic。
- 允许倾斜贴纸（rotate(-6deg)），每页 ≤1 组。
- 按压态统一 `opacity: 0.7`；微动效 ≤250ms。

### 1.3 导航行规则

- 改为**自定义导航**（`navigationStyle: custom`），与首页同源。
- 导航行左侧留空，**右侧为系统胶囊保留区，禁止放任何元素**。
- 标题交给内容区「态度头」，删除 v1 的重复大标题「我的」。

## 2. v1 问题回顾（为什么重构）

| 问题 | 等级 | 说明 |
|---|---|---|
| **设置页气质** | P0 | 顶部小标题 + 圆角卡片 + 菜单列表，像系统设置，没有滑手身份感。 |
| **身份牌缺位** | P0 | 头像、昵称、滑龄、风格这些「街头身份」元素被压成左图右文的紧凑行，没有排面。 |
| **数据带无焦点** | P1 | 三列等权数字，没有强调滑手最核心的「签到」。 |
| **菜单冰冷** | P1 | 图标 + 文字 + 箭头的标准列表，与首页贴纸/胶囊语言不连通。 |
| **弹窗形态割裂** | P2 | 编辑资料用居中卡片，其它页弹层全是底部 sheet。 |
| **营销化文案** | P2 | 「解锁专属身份」违反内容克制（v1 已改，v2 保持）。 |

v2 核心动作：**立身份牌、数据带减重、菜单贴纸化、弹层统一**。

## 3. 信息架构 v2

### 3.1 模块顺序

```
① 态度头（无卡片）
   ├─ 大字标「档案」（斜体 72rpx）
   ├─ slogan「这是你的轨迹。」（橙色 36rpx）
   └─ 品牌橙短条（80×8rpx）
② 滑手 ID 卡（rider-pass，整卡可点 → 编辑 sheet）
   ├─ 顶部橙色渐变条（8rpx，卡内满宽）
   ├─ 头像 144rpx（橙环 4rpx 描边，无头像时首字橙渐变底）
   ├─ 昵称（斜体 48rpx）
   ├─ 元信息行「城市 · 滑龄」
   ├─ 风格贴纸行（擅长标签，描边贴纸样式）
   └─ 完善提示「点击完善资料」（条件显示）
③ 数据带（无卡片，竖分隔线）
   ├─ 签到 86（橙，italic 48rpx）
   ├─ 打卡 12（白）
   └─ 推荐 3（白）
④ 我的参与（卡片）
   ├─ 分组头「我的参与」
   ├─ 我的打卡 / 我的推荐 / 我的报错 / 你提我改
   └─ 行：橙色图标方块 + 标签 + 数量 + 箭头
⑤ 管理（仅管理员，卡片）
   └─ 运营管理
⑥ 编辑资料底部 Sheet
```

### 3.2 v1 → v2 变化一览

| 维度 | v1 | v2 |
|---|---|---|
| 页面头 | 无（原生标题「我的」） | 斜体大字标「档案」+ slogan + 橙条 |
| 身份区 | 左图右文紧凑行 | 滑手 ID 卡：顶部橙条 + 144rpx 橙环头像 + 48rpx 斜体昵称 + 贴纸标签 |
| 数据带 | 卡片三列，40rpx | **无卡**三列，48rpx 斜体数字，签到橙 |
| 擅长标签 | 橙底胶囊 | 描边贴纸（2rpx 橙边 + 微倾斜） |
| 菜单 | 裸图标 + 文字 | 橙色图标方块（72rpx 圆角底）+ 文字 |
| 编辑资料 | 居中卡片 | 底部 sheet（与全站弹层统一） |

### 3.3 首屏验收标准

iPhone 标准屏不滚动必须看到：**态度头 + ID 卡完整 + 数据带**。用户第一眼确认「这是我，我滑了多少」。

## 4. 态度头

容器：`padding: 0 32rpx; margin-bottom: 32rpx;`

| 元素 | 规范 |
|---|---|
| 大字标 | `档案` / **72rpx** / `700` / `italic` / `#FFFFFF` / `letter-spacing: -1rpx`。 |
| slogan | `这是你的轨迹。` / `36rpx` / `500` / `#FF5A36`。与签到页 slogan「把每天留在街头。」呼应，构成同一语系。 |
| 品牌短条 | `80rpx × 8rpx` / 圆角 999rpx / `#FF5A36` / margin-top 24rpx。 |

## 5. 滑手 ID 卡（Rider Pass）

容器：

```css
background: #1E1E23;
border: 1rpx solid #26262C;
border-radius: 24rpx;
overflow: hidden; /* 让顶部橙条贴边 */
margin: 0 32rpx 32rpx;
```

### 5.1 结构

```
▔▔▔▔ 顶部橙色渐变条（8rpx，linear-gradient(90deg, #FF5A36, #FF8A6E)）
[头像 144rpx 橙环]   昵称（斜体 48rpx）        [→]
                     深圳 · 滑龄 3-5 年
                     [街式] [碗池] [平花]（贴纸）
```

### 5.2 元素规范

| 元素 | 规范 |
|---|---|
| 顶部橙条 | 高度 `8rpx`，满宽，`linear-gradient(90deg, #FF5A36, #FF8A6E)`。ID 卡的「卡缘」，身份感来源。 |
| 头像 | `144rpx` 圆形，`border: 4rpx solid #FF5A36`。无头像时首字占位：橙渐变底 + 白字 `56rpx / 700`。 |
| 昵称 | `48rpx` / `700` / `italic` / `#FFFFFF`，单行截断。 |
| 元信息行 | `28rpx` / `#A6A6AD`，`城市 · 滑龄 {n}`，未设置项显示「未设置」。pin 图标用橙 `#FF8A6E`。 |
| 风格贴纸 | 擅长标签改为**描边贴纸**：`22rpx` / `700` / `#FF8A6E` / 透明底 / `border: 2rpx solid rgba(255,90,54,0.55)` / 圆角 8rpx / 首个 `rotate(-3deg)` 微倾斜。最多 5 个，一行放不下换行。 |
| 编辑箭头 | `32rpx` / `#A6A6AD`，右缘垂直居中。 |
| 完善提示 | 仅资料不完整：`24rpx` / `#FF8A6E` / `点击完善资料`，位于贴纸行下方。 |
| 整卡行为 | 点击打开编辑 sheet，`hover-class="hv"`。 |

### 5.3 资料不完整态

- 头像首字「滑」占位；昵称「滑手」；元信息「未设置 · 未设置」；无贴纸；显示完善提示。
- 顶部橙条保留（空身份牌也是身份牌）。

## 6. 数据带（无卡片）

容器：`padding: 0 32rpx; margin-bottom: 40rpx;`，三列等宽，列间 1rpx `#26262C` 竖线。

### 6.1 结构

```
86          12          3
签到        打卡        推荐
```

### 6.2 元素规范

| 元素 | 规范 |
|---|---|
| 数字 | `48rpx` / `700` / `italic` / `line-height: 1`。签到数字 `#FF5A36`，其余 `#FFFFFF`。 |
| 标签 | `24rpx` / `#8C8C94`，margin-top 8rpx。 |
| 按压 | 整列可点，`opacity: 0.7`。 |
| 跳转 | 签到 → `switchTab` 签到页；打卡 → `pages/my-posts`；推荐 → `pages/submit`。 |

> 数据带去掉卡片底：数字本身就是内容，卡片只是包装。与签到页 Hero 的「裸数据」语言一致。

## 7. 我的参与（卡片）

容器：`background: #1E1E23; border: 1rpx solid #26262C; border-radius: 24rpx; margin: 0 32rpx 32rpx;`

### 7.1 分组头

- `我的参与` / `28rpx` / `700` / `#FFFFFF` / `padding: 32rpx 32rpx 16rpx`。

### 7.2 菜单项

| 项 | 图标 | 值 | 跳转 |
|---|---|---|---|
| 我的打卡 | 图片 | `{{postCount}} 条` | `pages/my-posts` |
| 我的推荐 | 地图 pin | `{{submissionCount}} 条` | `pages/submit` |
| 我的报错 | 旗帜 | `{{reportCount}} 条` | `pages/reports` |
| 你提我改 | 纸飞机 | `{{feedbackCount}} 条` | `pages/feedback` |

### 7.3 行规范（v2 图标方块）

- 行高 `104rpx`，分隔线 `1rpx #26262C`，末行无。
- **图标方块**：`72rpx × 72rpx` 圆角 `16rpx`，底 `rgba(255,90,54,0.12)`，图标 `32rpx` 橙 `#FF8A6E`。让菜单与首页的胶囊/贴纸语言连通。
- 标签 `30rpx / #FFFFFF`；值 `28rpx / #8C8C94`；箭头 `32rpx / #A6A6AD`。
- 按压 `opacity: 0.7`（不用背景色变）。

### 7.4 管理分组（仅管理员）

- 独立卡片 + 分组头 `管理`，仅一项 `运营管理`，样式同上。

## 8. 编辑资料底部 Sheet

与全站弹层（首页地图 / 详情页评分·报错·打卡）形态统一。

### 8.1 容器

- 高度 `85vh`，顶部圆角 `32rpx`，背景 `--sheet #232329`，顶部描边 `--sheet-line #2F2F36`。
- 遮罩 `rgba(0,0,0,0.55)`，点击关闭（保存中禁止）。
- 入场 `translateY(100%) → 0`，`250ms ease-out`。

### 8.2 头部

- 把手：`64×8rpx / #2A2A31 / 圆角 999rpx`，顶部居中。
- 标题 `编辑资料`：`34rpx / 700 / #FFFFFF`，居左。
- 保存：右上角文字按钮 `30rpx / #FF8A6E`；保存中显示「保存中…」+ `opacity 0.6` 禁用。

### 8.3 内容

- 头像区：`152rpx` 圆 + 橙色相机角标（`52rpx`，右下，`border: 4rpx solid #232329`），`open-type="chooseAvatar"`；提示 `点击更换头像 / 24rpx / #8C8C94`。
- 昵称：输入框 + 右侧 `n/12` 计数。
- 城市：整行可点 → `pages/city-picker`，右侧值 + 箭头。
- 滑龄：行内 chip 单选（1年内 / 1-3年 / 3-5年 / 5年以上）。
- 擅长：行内 chip 多选，上限 5；选中态 `橙边 + rgba(255,90,54,0.2) 底 + 白字`，未选 `#26262C` 底灰字。
- 字段间分隔线 `1rpx #26262C`。

## 9. 交互汇总

| 元素 | 行为 |
|---|---|
| ID 卡 | 点击 → 编辑 sheet |
| 数据带列 | 点击 → 对应页（签到 Tab / 我的打卡 / 推荐） |
| 菜单行 | 点击 → 对应列表页 |
| 遮罩 | 点击关闭 sheet（保存中除外） |
| 保存 | 校验昵称 → 传头像（如有新）→ 保存 → toast 关闭 |

## 10. 设计原则自检表

| 原则 | 落实点 |
|---|---|
| 信息层级清晰 | 态度头 → ID 卡 → 数据带 → 我的参与 → 管理；首屏可见态度头 + ID 卡 + 数据带。 |
| 视觉有态度 | 斜体大字标 + 顶部橙条 ID 卡 + 橙环头像 + 贴纸标签，身份牌气质而非设置页。 |
| 操作便捷 | 编辑入口 = 整张 ID 卡；数据带/菜单全部 1 步跳转。 |
| 轻量化 | 数据带去卡减重；动效 ≤250ms；弹层统一 sheet。 |
| 内容克制 | 无徽章/等级/激励文案；完善提示只留「点击完善资料」；数据全部真实。 |
| 包容但不平庸 | 新手看到明确的完善路径；老手一眼扫到数据与历史入口；大字高对比适合户外。 |
