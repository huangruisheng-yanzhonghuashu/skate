## 地图 bottom-sheet 重构（cover-view 解决原生组件层级问题）
- 用户反馈：在微信开发者工具中验证后，地图展开/收起仍然没有实现。
- 根因判断：`<map>` 是微信小程序原生组件，默认浮于普通 view 之上，会盖住同级的标题栏、关闭按钮、蒙层；且 `.map-sheet-map-wrap` 用 `flex:1` 继承高度，在部分场景下 map 渲染高度可能为 0。
- 重构改动：
  - `home.wxml`：将 `.map-sheet-body` 简化为 map 容器；把「手柄 + 标题 + 收起按钮」全部移入 `<map>` 内部，使用 `<cover-view>` 渲染，确保不被原生 map 覆盖；去掉 `catchtouchmove`。
  - `home.wxss`：`.map-sheet-body` 改为 `position:absolute; bottom:0; height:65vh`，给 `<map>` 明确高度；新增 `.sheet-top-cover`/`.sheet-handle-cover`/`.sheet-head-cover`/`.sheet-title-cover`/`.sheet-close-cover`/`.sheet-bar-cover` 等 cover-view 专用样式；调整 `.map-chip` 的 `top` 到 `140rpx`，避开顶部操作区。
  - `home.js`：保留 `openMapSheet`/`closeMapSheet`/`preventScroll`；`node --check` 通过。
- 风险与注意：
  - `<cover-view>` 不支持 `box-shadow`/`transition`/`z-index`，部分视觉阴影会降级，不影响交互。
  - cover-view 的 `bindtap` 在基础库 2.x 后支持，当前项目基础库应已覆盖。
