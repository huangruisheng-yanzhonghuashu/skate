## SkateSpot 设计理念（用户钦定，评审与出稿均须对照）
核心关键词：街头、自由、年轻、活力。态度是"粗粝中有态度、简洁中有能量"，不是精致优雅。
四原则：
1. 信息层级清晰——户外快速扫读，字号/对比度必须大而清晰
2. 视觉有态度——深色/水泥灰底 + 高饱和荧光色点缀（橙 #FF5A36 品牌色；绿 #00D4AA 仅限"在场/在线"语义）
3. 操作便捷——签到/导航/筛选等核心操作 1-2 步内完成
4. 轻量化——用完即走，不堆砌花哨动效（微动效 ≤250ms）
5. 内容克制——不加多余内容：无营销式激励文案（如"再打1天解锁xx徽章"）、无凑数模块；庆祝/结果态只反馈真实数据（签到成功+连续天数即止）。

## SkateSpot 产品规则（设计稿必须遵守）
- 签到必须依托场所：入口只在场所详情底部操作栏（导航/签到/发打卡/报错，定位硬校验，见 venue-detail.wxml）；Tab「签到」页是记录页（累计/日历/榜单/记录，见 checkins.wxml）。任何页面顶部不放全局「去签到」CTA——微信小程序右上角是胶囊按钮区，导航行右侧不可放操作。
- 小程序导航行右侧为胶囊保留区；城市切换在导航行左侧。
