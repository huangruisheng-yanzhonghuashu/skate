## 发现页内容预览 UI 设计 v1.3
- 用户反馈：视频预览返回应与首页场地详情一致，右下角操作组应为「点赞 / 评论 / 转发」，而非「点赞 / 关闭 / 转发」。
- 设计决策：
  - 视频预览不放置任何关闭按钮，退出走系统返回 / 左侧滑回，与首页场地详情返回方式一致。
  - 视频右下角竖排三个圆形操作按钮：点赞（心形）、评论（气泡 + 数量）、转发（分享）。
  - 评论按钮显示评论数量，数量为 0 时隐藏数字只显示气泡图标。
  - 图片预览保持不变：点击画面关闭、多图时顶部计数器 + 底部圆点。
  - 顶部继续禁止任何自定义按钮，避免与小程序系统胶囊/返回区冲突。

  - 更新 `design/MEDIA_VIEWER_DESIGN_SPEC.md` 为 v1.3。

## 视频预览发表评论 UI 设计 v1.4
- 用户要求：给出视频预览中发表评论的 UI 设计。
- 设计决策：
  - 点击视频预览右下角「评论」按钮，从底部拉起半屏评论面板（bottom-sheet）。
  - 面板默认占屏幕 60%，可拖拽上拉至 80%，背景遮罩 rgba(0,0,0,0.55)，点击遮罩关闭。
  - 面板背景 `#1E1E23`，顶部圆角 32rpx，包含顶部把手、标题「N 条评论」、关闭 ×。
  - 评论列表项：头像 64rpx、昵称、时间、内容、右侧点赞数（已点赞橙色）。
  - 底部输入区：圆角输入框「说点什么…」+ 发送按钮；无内容时置灰，有内容时橙色可点击。
  - 空态：评论数为 0 时列表居中显示「暂无评论，来说点什么吧」。
- 改动：
  - 更新 `design/MEDIA_VIEWER_DESIGN_SPEC.md` 为 v1.4，新增第 4 节「评论面板」。
  - 更新 `design/media-viewer-mockup.html`，新增「视频预览 + 评论面板」画板。
- 本次只输出 UI 设计，未修改代码。

## 视频预览改为独立页面 v1.5（重要架构决策）
- 用户反馈：视频预览应如首页列表进入场地详情页面一样，导航栏有返回按钮，支持右滑返回。
- 设计决策（关键）：
  - **视频预览 = 独立页面** `pages/video-preview/video-preview`，navigateTo 跳转，不再是发现页内遮罩。
  - **图片预览 = 页面内遮罩** `media-viewer` 组件，点击图片关闭，保持不变。
  - 视频页自定义透明导航栏：左侧白色返回按钮（88×88rpx 触控区），右侧系统胶囊保留区不放任何元素。
  - 返回三方式：导航栏返回按钮 / iOS 右滑手势 / Android 系统返回键（与场地详情页一致）。
  - 页面参数 URL query 传 postId，页面内拉取数据，避免 URL 传超长 cloud:// 路径。
  - 返回时点赞数/评论数回写发现页 feed 项。
  - 评论面板保持在视频页内作为 bottom-sheet，面板遮罩覆盖导航栏，先关面板再返回。
- 为什么独立页面：视频有播放状态+评论等重交互，独立页面有完整生命周期与系统返回手势，且避免遮罩内自绘返回按钮与右上角胶囊冲突。
- 改动：
  - 更新 `design/MEDIA_VIEWER_DESIGN_SPEC.md` 为 v1.5（结构调整：第 3 节改为独立页面，新增载体对比表与胶囊避让原则）。
  - 更新 `design/media-viewer-mockup.html`，视频画板加导航栏（返回按钮+胶囊区虚线示意）。
  - 同步更新 `design/DISCOVER_DESIGN_SPEC.md` 第 5 条交互规则。
- 本次只输出 UI 设计，未修改代码。落代码时需新建 video-preview 页面并注册到 app.json。
